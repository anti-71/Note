## 跟踪数据包

在实时模式下，先让 3 个计算机互相发送一个数据包，配置$ARP$表

## 数据包发送流程

##### 阶段 1：多设备同时发起通信

- 计算机 0 向计算机 1 发送$ICMP$数据；
- 同一时刻，计算机 2 也向计算机 1 发送$ICMP$数据

总线型网络的特点是 “所有设备共享同一传输介质”，此时已出现数据发送竞争

##### 阶段 2：集线器转发与冲突处理

- 0.001 秒：集线器 0 分别接收到计算机 0 和计算机 2 的$ ICMP $数据，产生冲突；
- 0.002 秒：
  1. 集线器 0 将数据转发给所有计算机；
  2. 计算机直接丢弃该帧
