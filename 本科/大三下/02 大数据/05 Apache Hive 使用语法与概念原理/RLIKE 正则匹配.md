##### 正则表达式

**正则表达式** 是一种规则集合，通过特定的规则字符描述，来判断字符串是否符合规则

| 字符 | 匹配逻辑 | 示例 |
| :--- | :--- | :--- |
| **.** | 任意单个字符（除换行符外） | `jav.` 匹配 `java` |
| **[ ]** | 匹配 [ ] 中的任意一个字符 | `[abc]va` 匹配 `ava` 或 `bva` |
| **-** | 在 [ ] 内表示字符范围 | `[a-z]av[a-g]` 匹配 `java` |
| **^** | 在 [ ] 开头表示取反（匹配不在范围内的字符） | `[^b-f]va` 匹配 `ava` |
| **\|** | 或逻辑（匹配 x 或 y） | `x\|y` 匹配 `x` 或 `y` |
| **\\** | 转义符（将特殊字符标记为文本或反向引用） | `\(` 匹配 `(` |
| **$** | 匹配字符串结尾（或多行模式下行尾） | `;$` 匹配位于行末的 `;` |
| *** ** | 匹配前面的字符零次或多次 | `zo*` 匹配 `z` 或 `zoo` |
| **+** | 匹配前面的字符一次或多次 | `zo+` 匹配 `zo` 或 `zoo` |
| **?** | 匹配前面的字符零次或一次 | `zo?` 匹配 `z` 或 `zo` |
| **{n}** | 正好匹配 n 次（n 为非负整数） | `o{2}` 匹配 `food` 中的 `oo` |
| **{n,}** | 至少匹配 n 次 | `o{2,}` 匹配 `foood` 中的所有 `o` |
| **{n,m}** | 匹配至少 n 次，至多 m 次 | `o{1,3}` 匹配 `foood` 中的三个 `o` |
| **\p{P}** | 匹配任意标点字符 | `J\p{P}a` 匹配 `J?a` |
| **\b** | 匹配一个单词边界 | `va\b` 匹配 `java` 中的 `va` |
| **\B** | 匹配非单词边界 | `va\B` 匹配 `javar` 中的 `va` |
| **\d** | 匹配数字字符 | `1[\d]` 匹配 `13` |
| **\D** | 匹配非数字字符 | `[\D]java` 匹配 `Java` |
| **\w** | 匹配单词字符（字母、数字、下划线） | `[\w]ava` 匹配 `java` |
| **\W** | 匹配非单词字符 | `[\W]java` 匹配 `$java` |
| **\s** | 匹配空白字符（空格、制表符等） | `Java\s2` 匹配 `Java 2` |
| **\S** | 匹配非空白字符 | `j[\S]va` 匹配 `java` |
| **\f** | 匹配换页符 | 等效于 `\x0c` |
| **\n** | 匹配换行符 | 等效于 `\x0a` |

##### RLIKE

Hive 中提供 RLIKE 关键字，可以供用户使用正则和数据进行匹配

我们以上一节中使用的订单表为例，来简单使用一下 RLIKE 正则匹配

- 查找广东省的数据

```sql
SELECT * FROM itheima.orders WHERE useraddress RLIKE '.*广东.*';
```

- 查找用户地址是：xx 省 xx 市 xx 区的数据

```sql
SELECT * FROM itheima.orders WHERE useraddress RLIKE '..省 ..市 ..区';
```

- 查找用户姓为张、王、邓

```sql
SELECT * FROM itheima.orders WHERE username RLIKE '[张王邓]\\S+';
```

- 查找手机号符合：188\*\*\*\*0\*\*\* 规则

```sql
SELECT * FROM itheima.orders WHERE userphone RLIKE '188\\S{4}0\\S{3}';
```
