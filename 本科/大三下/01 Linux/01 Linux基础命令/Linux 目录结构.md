### 一、Linux 的目录结构

Linux 的目录结构是一个 **树型结构**

Windows 系统可以拥有多个盘符，如 C 盘、D 盘、E 盘

Linux 没有盘符这个概念，只有一个根目录/，所有文件都在它下面

### 二、Linux 路径的描述方式

- 在 Linux 系统中，路径之间的层级关系，使用: / 来表示
- 在 Windows 系统中，路径之间的层级关系，使用:\ 来表示

>[!note]
> - 开头的/表示根目录
> - 后面的/表示层级关系
