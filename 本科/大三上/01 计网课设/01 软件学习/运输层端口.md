##### 配置网络设备

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/e39b0682c0184d8ca3cf888ab22dd5ed.png)

配置 IPv4 Address 略，要配置主机的“DNS 服务器”项为 192.168.0.2

##### 配置 DNS

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/58c265fefcd3441898ee24c66cf34611.png)

单击 DNS 服务器，选择“服务” - “DNS”，打开“DNS 服务”，名称填域名，地址填 Web 服务器 IP，点击“添加”即可

##### 跟踪数据包

事件列表筛选 DNS、HTTP

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/85ba6a8baa67447a93098d77b01128e3.png)

单击用户 PC，选择“桌面” - “网页浏览器”，在 URL 属于域名，即可发起 HTTP 请求
