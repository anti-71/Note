软件工程的开发过程和测试过程应该是对应的

##### 单元测试

**目的** 保证每个模块单独运行正确

**对象** 软件设计的最小单位——模块

**依据** 详细设计描述

多采用白盒测试法

##### 集成测试

集成测试是组装软件的系统测试技术，按设计要求把通过单元测试的各个模块组装在一起之后，进行集成测试以便发现与接口有关的各种缺陷

主要测试软件结构问题，多为黑盒测试

**非增量式集成** 把所有模块按设计要求一次全部组装起来，然后进行整体测试，容易出现混乱

**增量式集成方法** 程序一段一段地扩展，分为自顶向下集成和自底向上集成

| 集成测试类型 | 优点 | 缺点 |
| - | - | - |
| 自顶向下集成测试 | 能够尽早对主控模块及其决策机制进行测试，以便尽早发现主控模块中存在的问题 | 底层模块采用桩模块替代，无法真实反映底层模块实际情况；底层模块真实处理数据不能及时回送上层，易导致测试不充分 |
| 自底向上集成测试 | 不用桩模块，底层模块数据处理能得到真实反馈；测试用例设计相对简单 | 顶层主控模块最后才能测试，无法及时发现和掌握主控模块中的缺陷和问题 |
