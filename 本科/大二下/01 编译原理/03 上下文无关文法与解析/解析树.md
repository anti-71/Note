**解析树（Parse Tree）** 是对应于推导的标记树，直观地表示语法结构

##### 解析树的定义

解析树具有以下性质：
- **内部节点**由非终结符标记
- **叶节点**由终结符标记
- 每个内部节点的子节点表示在推导步骤中替换相应非终结符的方式

推导 $exp \implies exp\ op\ exp \implies number\ op\ exp \implies number + exp \implies number + number$ 对应的解析树：

```
        exp
       / | \
    exp op exp
     |   |   |
  number + number
```

##### 解析树与推导

同一个解析树通常对应于许多推导，所有这些推导都代表了解析字符串的相同基本结构

可以区分出与解析树唯一相关的特定推导：

- **最左推导（Leftmost Derivation）**：在每一步推导中替换最左边的非终结符，对应于其相关解析树的内部节点的前序编号
- **最右推导（Rightmost Derivation）**：在每一步推导中替换最右边的非终结符，对应于其相关解析树的内部节点的后序编号

##### 解析树示例

对于表达式 `(34-3)*42` 的解析树：

```
        exp
       / | \
     exp op exp
     |   |   |
  ( exp ) * number
    / | \
number - number
```

##### 求法（最左推导）

1. 从起始符号开始
2. 从左到右看每一项是不是终结符，若是，则跳过；若不是，则选择合适的产生式替换
3. 重复步骤 2，直至完全匹配上题目式子
4. 画解析树：参照推导过程，每替换一次，增加一个分支，节点是产生式右部的每一项

> [!note] 推导的非唯一性
