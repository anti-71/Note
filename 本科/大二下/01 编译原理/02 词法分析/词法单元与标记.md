##### 词法分析的基本任务

**词法分析**（Lexical Analysis）是编译的第一阶段，其输入是源程序的**字符序列**，输出是**词法单元序列**（Token Sequence）词法分析器通常称为**扫描器**（Scanner）

##### 词法单元（Token）、词素（Lexeme）、模式（Pattern）

- **词法单元（Token）**：由名称和可选属性值组成的抽象符号
  
  例如：`<id, 1>`、`<num, 42>`、`<,>`
- **词素（Lexeme）**：源程序中匹配某个 Token 模式的字符序列
  
  例如：`count`、`42`、`,`
- **模式（Pattern）**：描述一组词素必须满足的规则，通常用正则表达式描述

##### 常见词法单元分类

| 词法单元 | 示例词素 | 模式描述 |
|---------|---------|---------|
| **关键字** | `if` `else` `while` | 保留字的精确拼写 |
| **标识符** | `count` `sum` `_tmp` | 字母或下划线开头后跟字母/数字/下划线 |
| **字面量** | `42` `3.14` `"hello"` | 数字、字符串等常数 |
| **运算符** | `+` `-` `*` `/` | 算术/逻辑/关系运算符 |
| **分隔符** | `;` `,` `(` `)` `{` `}` | 标点符号 |
| **注释** | `// comment` | 被词法分析器丢弃的文本 |

##### 词法分析器的工作流程

```
源程序字符序列
       ↓
  预处理（删除空白、注释等）
       ↓
  扫描字符，分组为词素
       ↓
  匹配模式，生成 Token
       ↓
  Token 序列 → 语法分析器
```

##### 词法分析与语法分析的分工

- **读取字符**并**分组为词素**属于词法分析阶段
- **组装词素为语法结构**（表达式、语句等）属于语法分析阶段
- 将词法分析分离出来的原因：简化编译器设计（关注点分离）、提高效率（专用自动机）、增强可移植性
