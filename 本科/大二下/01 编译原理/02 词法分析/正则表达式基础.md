##### 正则表达式的定义

**正则表达式**（Regular Expression, RE）是一种用于描述**词法模式**的形式化语言它基于三个基本运算：

- **并运算（Union）**：`r | s` 表示语言 L(r) ∪ L(s)
- **连接运算（Concatenation）**：`r s` 表示语言 { ab | a∈L(r), b∈L(s) }
- **闭包运算（Closure/Kleene Star）**：`r*` 表示零次或多次重复，即 ∪_{i=0}^{∞} L(r)^i

##### 正则表达式的归纳定义

**基础规则：**

1. **空串** `ε` 是正则表达式，表示语言 `{ε}`
2. **空集** `∅` 是正则表达式，表示语言 `∅`
3. **字符** `a`（单个字母表字符）是正则表达式，表示语言 `{a}`

**归纳规则：**

若 `r` 和 `s` 是正则表达式，则以下也是正则表达式：

| 表达式 | 描述的语言 | 含义 |
|-------|-----------|------|
| `(r)` | L(r) | 分组，改变优先级 |
| `r \| s` | L(r) ∪ L(s) | 并（或） |
| `r s` | L(r) · L(s) | 连接 |
| `r*` | L(r)* | Kleene 闭包（零次或多次） |

##### 运算优先级

正则表达式运算的优先级从高到低为：

1. `*`（闭包） — 最高优先级，左结合
2. 连接（隐式或显式） — 次高，左结合
3. `|`（并） — 最低优先级，左结合

```text
// 示例：正则表达式 ab|cd* 的解析
// 等价于 (ab)|(c(d*))，而非 a(b|c)d*
```

##### 正则表达式的语言

给定字母表 Σ，正则表达式描述的语言是 Σ* 的子集例如：

- `a*` 表示所有由零个或多个 `a` 组成的字符串：`{ε, a, aa, aaa, ...}`
- `a|b` 表示单字符集合：`{a, b}`
- `a(a|b)*b` 表示以 `a` 开头以 `b` 结尾的字符串

##### 正则表达式与模式匹配的对应

```text
正则表达式 r | s    →   模式匹配：r 或 s
正则表达式 r s     →   模式匹配：r 后跟 s
正则表达式 r*      →   模式匹配：零个或多个 r
```

##### 等价规则

- `r(s|t) = rs|rt`（分配律）
- `(r|s)t = rt|st`（分配律）
- `r|s = s|r`（交换律）
- `(r|s)|t = r|(s|t)`（结合律）
- `r(st) = (rs)t`（结合律）
- `rε = εr = r`（单位元）
- `r|∅ = ∅|r = r`（零元）
- `∅* = ε`（空集闭包等于 ε）
- `ε* = ε`（ε 闭包等于 ε）
- `r** = r*`（幂等）
