##### 扩展元字符概述

在实际的词法分析器中，正则表达式在基础运算之上扩展了若干**语法糖**（Syntactic Sugar），简化常用模式的书写这些扩展功能可以等价转换为基本运算

##### 零次或一次：`?`

`r?` 表示 `r` 出现零次或一次，等价于 `r | ε`

```python
# 示例：整数（可选符号）
integer = "[+-]?[0-9]+"
# 匹配：+5, -3, 42
```

##### 一次或多次：`+`

`r+` 表示 `r` 出现一次或多次，等价于 `r r*`

```python
# 示例：至少一个数字
digit_sequence = "[0-9]+"
# 匹配：1, 23, 456（但不匹配空串）
```

##### 字符集合：`[ ]`

**字符集合**（Character Class）`[...]` 表示括号内任意单个字符，等价于用 `|` 连接所有字符：

```python
# [abc] 等价于 a|b|c
letter = "[a-zA-Z]"  # 所有英文字母
hex_digit = "[0-9a-fA-F]"  # 十六进制数字
```

字符集合内部支持：
- **范围表示**：`[a-z]` 表示 a 到 z 的连续范围
- **多范围组合**：`[a-zA-Z0-9]` 组合多个范围

##### 取反字符集合：`[^ ]`

`[^...]` 表示不在括号内的任意单个字符：

```python
# [^abc] 匹配除 a、b、c 外的任意字符
not_digit = "[^0-9]"  # 匹配非数字字符
```

等价于从整个字母表中排除集合中的字符

##### 任意字符：`.`

`.` 表示**除换行符外**的任意单个字符：

```python
# ... 匹配任意三个字符（除换行外）
any_three = "..."
# a.b 匹配 a 后跟任意字符再跟 b，如 axb, a9b
```

词法分析中很少直接使用 `.`，因为词法模式通常需要精确匹配

##### 转义字符：`\`

使用反斜杠转义元字符本身，或表示预定义字符类：

```python
# 转义元字符本身
digit_char = "[0-9]"
plus_literal = r"\+"  # 匹配 '+' 字符本身
star_literal = r"\*"  # 匹配 '*' 字符本身

# 常见预定义字符类（在许多工具中）
# \d → [0-9], \w → [a-zA-Z0-9_], \s → [ \t\n\r\f]
```

##### 边界匹配：`^` `$`

- `^r` 表示字符串开头
- `r$` 表示字符串结尾

```python
# ^[a-z]   - 以小写字母开头的字符串
# [0-9]$   - 以数字结尾的字符串
```

##### 扩展运算的等价转换

所有扩展操作都可等价转换为基础运算：

| 扩展操作 | 等价基础表达式 |
|---------|---------------|
| `r?` | `r \| ε` |
| `r+` | `r r*` |
| `[abc]` | `a\|b\|c` |
| `[^abc]` | 排除 a、b、c 后的所有字符 |
| `.` | 排除换行符后的所有字符 |
