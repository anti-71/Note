##### 子集构造法概述

**子集构造法**（Subset Construction）是将 NFA 转换为等价 DFA 的算法其核心思想是将 NFA 状态集合的每个子集作为 DFA 的一个状态，从而消除非确定性

##### 核心概念：ε-闭包（ε-Closure）

状态集 **S** 的 ε-闭包包含：
- S 中的所有状态
- 从 S 中任一状态通过零次或多次 ε 转移可达的所有状态

```python
def epsilon_closure(nfa, states):
    """计算状态集合的 ε-闭包"""
    closure = set(states)
    stack = list(states)
    
    while stack:
        state = stack.pop()
        for next_state in nfa.epsilon_transitions[state]:
            if next_state not in closure:
                closure.add(next_state)
                stack.append(next_state)
    
    return closure
```

##### 子集构造法算法

```python
def subset_construction(nfa):
    """将 NFA 转换为 DFA（子集构造法）"""
    # DFA 的初始状态是 NFA 初始状态的 ε-闭包
    dfa_start = epsilon_closure(nfa, {nfa.start_state})
    
    # DFA 状态集 = NFA 状态子集的集合
    dfa_states = {dfa_start}
    dfa_transitions = {}
    dfa_accept = set()
    
    worklist = [dfa_start]  # 待处理的工作列表
    
    while worklist:
        dfa_state = worklist.pop()
        
        # 若该状态包含 NFA 的任何接受状态，则其为 DFA 接受状态
        if any(s in nfa.accept_states for s in dfa_state):
            dfa_accept.add(dfa_state)
        
        # 对每个输入字符计算目标状态
        for char in nfa.alphabet:
            # 从当前状态集经 char 转移可达的状态
            move_set = set()
            for nfa_state in dfa_state:
                if char in nfa.transitions[nfa_state]:
                    move_set.update(nfa.transitions[nfa_state][char])
            
            # 计算 ε-闭包 = DFA 的下一个状态
            next_state = epsilon_closure(nfa, move_set)
            
            if next_state:
                dfa_transitions[(dfa_state, char)] = next_state
                
                if next_state not in dfa_states:
                    dfa_states.add(next_state)
                    worklist.append(next_state)
    
    return DFA(dfa_states, dfa_start, dfa_transitions, dfa_accept)
```

##### 构造示例

**NFA**（对应 a|b）：

```text
      ε        a
    ┌────→ [q₁] ──→ [q₂]
    │                  │
→ [q₀] ── ε ──→ [q₃] ─┤── ε → [q₅]
         ε      └──→ [q₄] ┘    ↑
                b              │
                └────── ε ─────┘
```

**DFA（子集构造结果）：**

| DFA 状态 | NFA 状态子集 | 在 a 上转移 | 在 b 上转移 | 接受? |
|---------|-------------|------------|------------|------|
| A | {q₀, q₁, q₃, q₅} | B | C | 是 |
| B | {q₂, q₅} | ∅ | ∅ | 是 |
| C | {q₄, q₅} | ∅ | ∅ | 是 |
| D | ∅ | D | D | 否 |

##### 死状态的处理

子集构造中可能出现**空集状态** ∅——表示从该状态无有效转移在完整 DFA 中，需为缺失的转移补充指向死状态的转移：

```python
# 添加死状态处理
dead_state = frozenset()  # 空集作为死状态
dfa_states.add(dead_state)

# 对所有状态补充完整转移
for state in dfa_states:
    for char in alphabet:
        if (state, char) not in dfa_transitions:
            dfa_transitions[(state, char)] = dead_state

# 死状态的自环
for char in alphabet:
    dfa_transitions[(dead_state, char)] = dead_state
```

##### 算法复杂度

- **时间复杂度**：最坏情况 **O(2ⁿ)**，其中 n 是 NFA 的状态数
- **空间复杂度**：最坏情况 DFA 状态数指数于 NFA 状态数
- **实际表现**：对词法分析中的常见正则表达式，DFA 状态数通常接近 NFA 状态数

##### 子集构造法在编译器中的位置

```text
正则表达式 → Thompson构造法 → NFA → 子集构造法 → DFA → DFA最小化 → minDFA
```

子集构造法是流水线的第二步，将非确定性的 NFA 转化为可高效执行的 DFA
