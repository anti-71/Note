##### 数字字面量的模式

**整数字面量**（Decimal Integer）的模式：

```python
digit = [0-9]
integer = digit+
# 匹配：0, 1, 42, 999
```

**浮点数字面量**的模式：

```python
digit = [0-9]
float_lit = digit+ "." digit+  |  digit+ "."  |  "." digit+  |  digit+ ("." digit+)? ([eE] [+-]? digit+)?
# 匹配：3.14, .5, 2., 1e10, 2.5e-3
```

**十六进制字面量**的模式：

```python
hex_digit = [0-9a-fA-F]
hex_int = "0x" hex_digit+  |  "0X" hex_digit+
# 匹配：0xFF, 0x1a, 0xdeadbeef
```

##### 标识符的模式

典型的编程语言**标识符**（Identifier）以字母或下划线开头，后跟零个或多个字母、数字或下划线：

```python
letter = [a-zA-Z_]
alnum = [a-zA-Z0-9_]
identifier = letter alnum*
# 匹配：foo, _tmp, count, var_1, __init__
```

##### 关键字的模式

关键字是特殊的标识符，需要与普通标识符区分通常采用**最长匹配**（Longest Match）原则——若一个词素既可匹配关键字又可匹配标识符，优先匹配关键字：

```python
# 先查关键字表，再当作标识符
# 词法分析器中：先匹配标识符模式，然后查表判断是否为关键字
```

##### 运算符的模式

```python
# 算术运算符
plus    = "+"
minus   = "-"
mul     = "*"
div     = "/"

# 关系运算符（注意多字符运算符的优先级）
relop   = "<=" | ">=" | "==" | "!=" | "<" | ">"

# 赋值运算符
assign  = "=" | "+=" | "-=" | "*=" | "/="
```

##### 注释的模式

**单行注释**：

```python
line_comment = "//" [^\n]*   # // 开头到行尾
```

**块注释**（不支持嵌套的版本）：

```python
block_comment = "/*" .* "*/"   # /* 和 */ 之间的任意内容
```

⚠️ 块的注释正则表达式在理论上是 **非正则的**（需要计数匹配的 `/*` 和 `*/`），实际词法分析器通常用**扩展的确定性自动机**来处理嵌套注释

##### 字符串字面量的模式

```python
string_lit = "\"" ("\\\"" | [^"\n])* "\"" 
# 匹配双引号字符串，支持转义引号，不支持换行
```

##### 空白字符的过滤

空白字符通常被词法分析器丢弃（不生成 Token）：

```python
whitespace = [ \t\n\r]+
# 词法分析器匹配后不产生 Token，直接继续扫描
```

##### 词法分析中的模式优先级

当多个正则表达式模式同时匹配时，使用以下规则决定：

1. **最长匹配**（Longest Match）：取能匹配的最长词素例如 `<=` 比 `<` 优先匹配
2. **模式顺序**：若长度相同，先声明的模式优先关键字模式通常在标识符之前声明
