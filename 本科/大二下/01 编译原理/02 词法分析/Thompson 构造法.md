##### Thompson 构造法概述

**Thompson 构造法**（Thompson's Construction）是将正则表达式转换为等价 NFA 的算法由 Ken Thompson 提出，其核心思想是将正则表达式的每种运算对应为 NFA 片段的组合

##### 基本 NFA 片段

**基础规则**——对应正则表达式的最小单元：

**规则 1 — 空串 ε：**

```text
   ε
q₀ ──→ q₁ (接受)
```

**规则 2 — 单个字符 a：**

```text
   a
q₀ ──→ q₁ (接受)
```

##### 组合 NFA 片段

**规则 3 — 并运算 r|s：**

```text
      ε      [NFA of r]
    ┌───→ ────→ ──→ ─┐
    │                 │     ε
→ q₀┤                 ├──→ q₁ (接受)
    │                 │
    └───→ ────→ ──→ ─┘
       ε     [NFA of s]
```

引入 ε 转移将两个子 NFA 并联

**规则 4 — 连接运算 rs：**

```text
→ [NFA of r] ──ε──→ [NFA of s] → (接受)
```

r 的接受状态通过 ε 转移到 s 的初始状态

**规则 5 — 闭包运算 r\*：**

```text
      ε
    ┌──────────────┐
    │              ▼
  q₀ ──ε──→ [NFA of r] ──ε──→ q₁ (接受)
    ▲                         │
    └─────────────────────────┘
              ε
```

引入新的初始和接受状态，允许跳过 r（直接接受）或循环执行 r

##### 构造示例：a|b\*

将正则表达式 `a|b*` 构造为 NFA：

```text
步骤 1: 构造 b 的 NFA
步骤 2: 构造 b* 的 NFA（闭包）
步骤 3: 构造 a 的 NFA
步骤 4: 将 a 和 b* 的 NFA 通过 ε 转移并联（并运算）

结果 NFA:
        ε        a
      ┌────→ q₁ ──→ q₂
      │                │
→ q₀ ─┤                ├──ε──→ q₃ (接受)
      │                │
      └────→ q₄ ──→ q₅ ┘
        ε    └──┬──┘    ε
                │←── ε ──┘
                └── ε ──→ q₆ (接受)
```

##### 算法复杂度

Thompson 构造法的时间和空间复杂度均为 **O(|r|)**，其中 |r| 是正则表达式的长度

| 运算 | 新增状态数 |
|-----|-----------|
| ε | 2 |
| a | 2 |
| r\|s | 2 + N(r) + N(s) |
| rs | N(r) + N(s) |
| r\* | 2 + N(r) |

##### Thompson NFA 的性质

- **精确一个接受状态**：每个 NFA 片段恰有一个接受状态
- **无转移进入初始状态**：初始状态没有入边
- **无转移离开接受状态**：接受状态没有出边
- **ε 转移数量**：O(|r|) 个

##### 构造法在编译器中的位置

```text
正则表达式 → Thompson 构造法 → NFA → 子集构造法 → DFA → 最小化 → 最优 DFA
         RE                     NFA          DFA           minDFA
```

Thompson 构造法是这一流水线的第一步，将人类可读的正则表达式转化为计算机可处理的 NFA 形式
