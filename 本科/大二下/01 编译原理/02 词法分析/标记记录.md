##### Token 记录的结构

词法分析器输出的每个 Token 通常用一个 **Token 记录**（Token Record）表示，包含两个主要部分：

- **Token 类型**：标识词法单元的种类（如 `ID`、`NUMBER`、`PLUS`）
- **属性值**：存储该 Token 的具体信息（如标识符名、数字值）

```c
// Token 记录结构示例
typedef struct {
    TokenType type;      // 词法单元类型枚举
    char* lexeme;        // 词素文本
    int line;            // 行号（用于错误报告）
    int column;          // 列号
    union {
        int intValue;    // 整数字面量
        float floatValue;// 浮点字面量
        char* strValue;  // 字符串/标识符
    } attr;
} TokenRecord;
```

##### Token 类型枚举

使用枚举类型定义所有可能的 Token：

```c
typedef enum {
    // 关键字
    TOKEN_IF, TOKEN_ELSE, TOKEN_WHILE, TOKEN_FOR,
    TOKEN_RETURN, TOKEN_INT, TOKEN_FLOAT, TOKEN_VOID,
    // 标识符和字面量
    TOKEN_ID, TOKEN_NUM, TOKEN_FLOAT_LIT, TOKEN_STRING_LIT,
    // 运算符
    TOKEN_PLUS, TOKEN_MINUS, TOKEN_MUL, TOKEN_DIV,
    TOKEN_ASSIGN, TOKEN_EQ, TOKEN_NEQ, TOKEN_LT, TOKEN_GT,
    // 分隔符
    TOKEN_SEMI, TOKEN_COMMA, TOKEN_LPAREN, TOKEN_RPAREN,
    TOKEN_LBRACE, TOKEN_RBRACE,
    // 特殊
    TOKEN_EOF, TOKEN_ERROR
} TokenType;
```

##### 单字符 Token 的处理

对于运算符、分隔符等单字符 Token，属性值通常为空，仅类型信息即可：

```c
// '+' → Token { type: TOKEN_PLUS, attr: null }
// ';' → Token { type: TOKEN_SEMI, attr: null }
```

##### 多字符 Token 的处理

对于标识符、数字等 Token，需要保留词素的属性值词法分析器通过**符号表**（Symbol Table）管理标识符属性：

```c
// "count" → Token { type: TOKEN_ID, attr: 指向符号表 "count" 的指针 }
// "42"    → Token { type: TOKEN_NUM, attr: { intValue: 42 } }
```

##### 位置信息的记录

Token 记录中的**行号和列号**对于编译器的错误报告至关重要，使编译器能精确定位错误位置：

```c
// 在语法分析阶段，错误信息可输出：
// "Error at line 5, column 12: expected ';'"
```

##### 关键字与标识符的区分

关键字是保留的标识符，词法分析器通过**关键字表**来区分普通标识符与关键字：

```python
# Python 风格的关键字表
keywords = {
    "if": TOKEN_IF, "else": TOKEN_ELSE, "while": TOKEN_WHILE,
    "for": TOKEN_FOR, "return": TOKEN_RETURN, "int": TOKEN_INT,
}

def get_token(identifier):
    if identifier in keywords:
        return Token(keywords[identifier])
    else:
        return Token(TOKEN_ID, identifier)
```
