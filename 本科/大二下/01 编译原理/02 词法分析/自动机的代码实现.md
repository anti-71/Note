##### 词法分析器的实现架构

有限自动机在词法分析器中有两种常见的代码实现方式：

1. **表驱动法**：用转移表表示 DFA，由通用驱动函数模拟
2. **直接编码法**：将自动机逻辑直接编写为代码（if-else / switch-case）

##### 表驱动法（Table-Driven）

转移表用二维数组表示，状态为行，输入字符为列：

```c
#define NUM_STATES 10
#define NUM_CHARS 128

// 转移表：transitions[state][char] = next_state
// -1 表示无转移（死状态）
int transitions[NUM_STATES][NUM_CHARS] = {
    /* 状态 0 */ { [0 ... 127] = -1, ['a']=1, ['b']=2 },
    /* 状态 1 */ { [0 ... 127] = -1, ['a']=3, ['b']=4 },
    // ...
};

// 接受状态标记
int accept_states[NUM_STATES] = { 0, 0, 1, 0, 1 };

// 表驱动的 DFA 模拟器
Token get_next_token() {
    int state = 0;  // 初始状态
    int last_accept = -1;
    int last_accept_pos = 0;
    char buffer[1024];
    int pos = 0;
    
    while (1) {
        char c = get_next_char();
        buffer[pos] = c;
        
        int next = transitions[state][(int)c];
        if (next == -1) break;  // 无转移
        state = next;
        pos++;
        
        if (accept_states[state]) {
            last_accept = state;
            last_accept_pos = pos;
        }
    }
    
    // 回退到最后一个接受位置（最长匹配）
    retract_to(last_accept_pos);
    return build_token(last_accept, buffer);
}
```

##### 直接编码法（Hand-Coded Scanner）

将自动机的转移逻辑直接编码为嵌套的 if-else 或 switch 语句：

```c
Token get_next_token() {
    char c = next_char();
    
    // 跳过空白
    while (c == ' ' || c == '\t' || c == '\n') {
        c = next_char();
    }
    
    // 标识符或关键字
    if (is_letter(c) || c == '_') {
        char lexeme[256];
        int i = 0;
        while (is_alnum(c)) {
            lexeme[i++] = c;
            c = next_char();
        }
        retract();  // 多读了一个字符，回退
        lexeme[i] = '\0';
        return check_keyword_or_id(lexeme);
    }
    
    // 数字字面量
    if (is_digit(c)) {
        int val = 0;
        while (is_digit(c)) {
            val = val * 10 + (c - '0');
            c = next_char();
        }
        retract();
        return make_token(TOKEN_NUM, val);
    }
    
    // 运算符
    switch (c) {
        case '+': return make_token(TOKEN_PLUS, 0);
        case '-': return make_token(TOKEN_MINUS, 0);
        case '*': return make_token(TOKEN_MUL, 0);
        case '/': 
            c = next_char();
            if (c == '/') skip_line_comment();
            else retract();
            return make_token(TOKEN_DIV, 0);
        // ...
    }
}
```

##### 标识符的有穷自动机

标识符模式 `([a-zA-Z_][a-zA-Z0-9_]*)` 对应的 DFA：

- **状态 0**：初始状态，未开始匹配
- **状态 1**：读入了首字符（字母或下划线），所有后继字符在此处理
- **状态 2**：读入了非法首字符（数字开头），进入死状态

```text
              letter | digit | _
              ┌──────────────┐
              ▼              │
    letter | _    ┌──────────┘
  q₀ ─────────→ q₁ ─────────→ q₂ (死状态)
                 (接受)
```

##### 自动机的代码实现架构

词法分析器的整体实现结构如下：

```text
                    源代码字符流
                         │
                    ┌────▼──────┐
                    │  缓冲管理  │
                    │ (Buffer)  │
                    └────┬──────┘
                         │
               ┌─────────▼──────────┐
               │   DFA 模拟器       │
               │ ← 转移表/直接编码  │
               │ ← 最长匹配逻辑    │
               │ ← 回退机制        │
               └─────────┬──────────┘
                         │
               ┌─────────▼──────────┐
               │  Token 构建器      │
               │ ← 查关键字表       │
               │ ← 组装属性值       │
               │ ← 记录位置信息     │
               └─────────┬──────────┘
                         │
                    Token 序列
```
