**中间代码生成（Intermediate Code Generation）** 生成平台无关的 **中间表示（IR）**

**常见形式**：
- **三地址码**：每条指令至多涉及三个操作数
- **四元式**：格式为 `(操作符, 操作数1, 操作数2, 结果)`
- **抽象语法树（AST）**：保留语法结构

**示例（三地址码）**：
```c
t1 = c * 2;
t2 = b + t1;
a = t2;
```
