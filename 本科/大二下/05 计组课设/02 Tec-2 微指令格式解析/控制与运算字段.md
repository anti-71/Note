##### MI 字段（B30-B28, B26-B24, B22-B20）

$MI_{8-0}$，AM2901 运算器芯片的 3 组 9 个控制信号

| I8-6 | 寄存器结果选择 | I5-3 | 运算功能 | I2-0 | 源 |
|:--|:--|:--|:--|:--|:--|
| 000 | F → Q | 000 | R + S | 000 | A, Q |
| 001 | 无 | 001 | S - R | 001 | A, B |
| 010 | F → B | 010 | R - S | 010 | 0, Q |
| 011 | F → B | 011 | R ∨ S | 011 | 0, B |
| 100 | F/2 → B, Q/2 → Q | 100 | R ∧ S | 100 | 0, A |
| 101 | F/2 → B | 101 | ¬R ∧ S | 101 | D, A |
| 110 | 2F → B, 2Q → Q | 110 | R ⊕ S | 110 | D, Q |
| 111 | 2F → B | 111 | R ⊙ S | 111 | D, 0 |

##### A 口 / B 口字段（B19-B16, B15-B12）

AM2901 寄存器组地址，$R_3 - R_0$ 和 $R_{15} - R_8$ 为通用寄存器，$R_7 - R_4$ 为专用寄存器

| 寄存器 | 功能 |
|:--|:--|
| R4 | SP 栈顶指针 |
| R5 | PC 指令地址（增量后） |
| R6 | IP 当前指令地址 |
| R7 | 单步专用 |

##### SA / SB 字段（B7, B3）

选择 A 口和 B 口寄存器地址的来源，SA=1 用 $IR_{3-0}$，SB=1 用 $IR_{7-4}$

##### SCi 字段（B11-B10）

最低位进位控制

| SCi | Cin |
|:--|:--|
| 0 | 0 |
| 1 | 1 |
| 2 | C |
| 3 | TCLK 方波 |

##### SSH 字段（B9-B8）

移位信号控制

| SSH | 左移 RAM₀ | 左移 Q0 | 右移 RAM₃ | 右移 Q3 |
|:--|:--|:--|:--|:--|
| 0 | 0 | X | 0 | X |
| 1 | C | X | C | X |
| 2 | Q₃ | $\overline{F3}$ | CY | RAM |
| 3 | X | X | F3 或 OV | RAM |
