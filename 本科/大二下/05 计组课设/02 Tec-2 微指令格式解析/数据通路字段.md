##### DC1 字段（B6-B4）

指定送往内部总线 IB 的数据来源

| DC1 | 控制端 | 送往 IB 的数据 |
|:--|:--|:--|
| 000 | $\overline{SWTOIB}$ | 开关手拨数据 |
| 001 | $\overline{RTOIB}$ | 运算器输出 |
| 010 | $\overline{ITOIB}$ | 指令低 8 位 |
| 011 | $\overline{FTOIB}$ | 状态寄存器 |
| 100 | $\overline{INTA}$ | 中断向量 |
| 101 | NC | 未使用 |
| 110 | $\overline{EI}$ | 开中断 |
| 111 | $\overline{DI}$ | 关中断 |

##### DC2 字段（B2-B0）

指定接收来自内部总线 IB 数据的寄存器

| DC2 | 控制端 | 接收 IB 数据的寄存器 |
|:--|:--|:--|
| 000 | NC | 未使用 |
| 001 | $\overline{GIR}$ | 指令寄存器 IR |
| 010 | $\overline{GAR}$ | 地址寄存器 AR |
| 011 | $\overline{GINTP}$ | 中断优先权 |
| 100 | CPLDR0 | LDR6 |
| 101 | CPLDR1 | LDR5, LDR4 |
| 110 | CPLDR2 | LDR3, LDR2 |
| 111 | CPLDR3 | LDR1, LDR0 |
