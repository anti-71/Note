每条微指令由 56 位组成，从高向低为 $B_{55} - B_0$，分为 13 个字段

##### 下地址字段（B55-B46）

10 位，用于给出下一条微指令的地址

##### CI 字段（B43-B40）

$CI_{3-1}$，用于给出 AM2910 的 16 种命令码编号

| 命令 | 功能 |
|:--|:--|
| 0 | 初始化，清除微堆栈，Y 输出为 0 |
| 1 | 条件转微子程序 |
| 2 | 指令功能分支，通过 MAP ROM 找入口地址 |
| 3 | 条件转移，条件成立时跳转 |
| 4 | 入栈并条件装入计数器，为循环做准备 |
| 6 | 条件转至中断向量 |
| 8 | 微程序循环控制，计数器非零时继续循环 |
| 10 | 条件返回 |
| 14 | 顺序执行 |
| 15 | 三路转移 |

##### SCC / SC 字段（B39-B37, B36）

3 位 SCC 和 1 位 SC，用于选择 AM2910 的条件判断信号 /CC

##### SST 字段（B34-B32）

控制标志寄存器写入，决定 C、Z、V、S 标志位的产生方式

##### 内存控制字段（B31, B27, B23）

控制内存读写、外设接口读写、微指令装入

| /MIO | REQ | /WE | 操作 |
|:--|:--|:--|:--|
| 0 | 0 | 0 | 存储器写 |
| 0 | 0 | 1 | 存储器读 |
| 0 | 1 | 0 | I/O 写 |
| 0 | 1 | 1 | I/O 读 |
| 1 | 0 | X | 不操作 |
| 1 | 1 | X | 装入微码 |
