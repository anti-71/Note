##### 序号 4：PC → AR, PC+1 → PC

`0000 0E00 A0B5 5402`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/c4adad437f79412f92f059424ed76932.png)

| 字段 | 值 | 说明 |
|:--|:--|:--|
| CI | 14 | 顺序执行 |
| /MIO, /REQ, /WE | 1,0,X | 不操作 |
| MI8-6 | 011 | Y 输出送 F 口，结果回 B |
| MI2-0 | 011 | 0 和 B 口 |
| A 口 / B 口 | R5 | PC |
| SCi | 1 | 进位为 1，实现 PC+1 |
| DC2 | /GAR | 运算器输出送 AR |

##### 序号 5：MEM → AR

`0000 0E00 10F0 0002`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/a3965ace8f4d456ca6f2132a9a9c6758.png)

与序号 2 相同：存储器读，运算器输出送 AR

##### 序号 6：QMEM - Q → Q

`0000 0E01 02E0 0000`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/690c654c08d24c7d96dde1a0a760f19f.png)

| 字段 | 值 | 说明 |
|:--|:--|:--|
| CI | 14 | 顺序执行 |
| SST | 0 | 接受 ALU 标志位 |
| /MIO, /REQ, /WE | 0,0,1 | 存储器读 |
| MI8-6 | 001 | Y 输出送 F 口，结果回 Q |
| MI5-3 | 010 | R - S（减法） |
| MI2-0 | 110 | D 和 Q |
| SCi | 0 | 进位为 0 |

##### 序号 7：Q → MEM, CC#=0

`0029 0300 1020 0010`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/cbcf988798e241a9a79b2b4d171a7b17.png)

| 字段 | 值 | 说明 |
|:--|:--|:--|
| 下地址 | A4 | 跳转执行，进行中断检测 |
| CI | 3 | 条件转移 |
| SCC | 000 | 判断 CC#=0 |
| /MIO, /REQ, /WE | 0,0,0 | 存储器写 |
| MI2-0 | 010 | 0 和 Q |
| SCi | 0 | 进位为 0 |
| DC1 | 001 | 运算器输出至 [AR] |
