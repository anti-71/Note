##### 序号 1：PC+1 → AR

`0000 0E00 90B5 5402`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/88892817aa114b6cbdaaae154f2c908e.png)

| 字段 | 值 | 说明 |
|:--|:--|:--|
| CI | 14 | 顺序执行 |
| /MIO, /REQ, /WE | 1,0,X | 不操作 |
| MI8-6 | 011 | Y 输出送 F 口，结果回 B |
| MI5-3 | 000 | R + S |
| MI2-0 | 011 | 0 和 B 口 |
| A 口 / B 口 | R5 | PC |
| SCi | 1 | 进位为 1，实现 PC+1 |
| DC2 | /GAR | 运算器输出送 AR |

##### 序号 2：MEM → AR

`0000 0E00 10F0 0002`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/bb9e9b5802e54458b2704fd4862f4429.png)

| 字段 | 值 | 说明 |
|:--|:--|:--|
| CI | 14 | 顺序执行 |
| /MIO, /REQ, /WE | 0,0,1 | 存储器读 |
| MI2-0 | 101 | D 和 0 |
| SCi | 0 | 进位为 0 |
| DC2 | /GAR | 运算器输出送 AR |

##### 序号 3：MEM → Q

`0000 0E00 00F0 0000`

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/91ba27f342784cd09efd7f24e16bc2a9.png)

| 字段 | 值 | 说明 |
|:--|:--|:--|
| CI | 14 | 顺序执行 |
| /MIO, /REQ, /WE | 0,0,1 | 存储器读 |
| MI8-6 | 000 | Y 输出送 F 口，F → Q |
| MI2-0 | 101 | D 和 0 |
| DC2 | NC | 未使用 |
