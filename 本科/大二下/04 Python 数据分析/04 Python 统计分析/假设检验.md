##### 基本步骤

1. 提出原假设和备择假设
2. 确定检验统计量
3. 规定显著性水平 $\alpha$
4. 计算检验统计量的值
5. 做出决策

##### 单样本 t 检验

比较假设的总体均值与样本均值的差异

$$
t = \frac{\overline{x} - \mu_0}{\sigma / \sqrt{n}}
$$

```python
import statsmodels.api as sm
d1 = sm.stats.DescrStatsW(data)
d1.ttest_mean(n)  # 返回 (t统计量, p值, 自由度)
```

##### 双样本 t 检验

比较两个样本的均值差异是否显著，常用于分析二分类变量区分下的连续型变量

```python
stats.levene(gender_0, gender_1)               # 方差齐性检验
stats.ttest_ind(gender_0, gender_1, equal_var=True)  # 独立样本 t 检验
```
