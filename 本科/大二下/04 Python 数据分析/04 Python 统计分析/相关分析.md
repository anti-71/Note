##### Pearson 相关系数

衡量两变量线性相关关系

$$
r = \frac{\sum_{i=1}^n (X_i - \overline{X})(Y_i - \overline{Y})}{\sqrt{\sum_{i=1}^n (X_i - \overline{X})^2} \sqrt{\sum_{i=1}^n (Y_i - \overline{Y})^2}}
$$

```python
df[['age', 'charges']].corr(method='pearson')
```

##### Spearman 相关系数

适用于有序变量

```python
df[['age', 'charges']].corr(method='spearman')
```
