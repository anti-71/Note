```python
stats.chi2_contingency(cross_table)
```

##### 方差分析

检验多个样本的均值是否有显著性差异

**单因素方差分析**：衡量不同因素对观测变量的影响
**多因素方差分析**：考虑多个分类变量的影响及交互效应

```python
from statsmodels.stats.anova import anova_lm
from statsmodels.formula.api import ols

model = ols('charges ~ c(children)', data=df).fit()
anova_lm(model)
```
