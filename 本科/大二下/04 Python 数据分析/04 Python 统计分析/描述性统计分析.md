##### 基本概念

**总体**：包含所有研究个体的集合
**样本**：从总体中抽样的部分个体

##### 统计量

常见统计量：均值、标准差、中位数、分位数、众数
离散程度：极差、四分位差、方差、变异系数（标准差 / 均值）

##### 点估计和区间估计

点估计用样本统计量估计总体参数
区间估计给出置信区间和置信度 $1 - \alpha$

$$
\left[\overline{x} - \frac{s}{\sqrt{n}}t_{\frac{\alpha}{2}}(n-1),\ \overline{x} + \frac{s}{\sqrt{n}}t_{\frac{\alpha}{2}}(n-1)\right]
$$

```python
from scipy import stats
se = stats.sem(data)                             # 标准误
stats.norm.interval(alpha, data.mean(), se)       # 正态分布置信区间
```

##### 中心极限定理

设均值为 $\mu$，方差为 $\sigma^2$ 的任意总体中抽取容量 $n$ 的样本，当 $n$ 充分大时，样本均值的抽样分布近似服从均值为 $\mu$、方差为 $\frac{\sigma^2}{n}$ 的正态分布
