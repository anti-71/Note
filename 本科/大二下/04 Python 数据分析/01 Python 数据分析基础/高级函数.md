##### lambda 函数

匿名函数，可以有若干个参数

```python
f = lambda x: x ** 2
f(1)  # 1
```

##### map 函数

将一个函数映射到序列的每一个元素上，生成新序列

##### reduce 函数

将前两个元素传给函数，结果与第三个元素继续传给函数，依次类推

```python
from functools import reduce
```

##### filter 函数

过滤序列，返回由符合条件元素组成的新序列
