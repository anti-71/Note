##### 转义字符

`\n` 换行，`\t` 制表符，`\b` 退格

```python
print(r'')  # 不理会字符串里的制表符
```

##### 字符串格式化

```python
print('%s' % a)           # % 格式化
print('{:}'.format(a))    # format 格式化
```

`s` 字符串，`d` 整数，`.nf` n 位浮点数，`.ne` n 位科学计数法，`%%` 输出 %

##### 字符串方法

```python
s.split(a)                # 以 a 分割
s.find(a)                 # 返回第一个匹配位序，无则返回 -1
s.lower()                 # 小写输出
s.upper()                 # 大写输出
s.capitalize()            # 首字母大写
"a".join(list)            # 用 a 间隔拼接 list 元素
s.replace(a, b)           # 将 a 替换为 b
s.strip()                 # 去掉首尾空格（lstrip / rstrip）
s.isdigit()               # 判断是否全由数字组成
s.startswith(a)           # 判断是否以 a 开头
s.endswith(a)             # 判断是否以 a 结尾
s.isalnum()               # 判断是否由数字和字母构成
s.count(a)                # 判断 a 出现次数
```
