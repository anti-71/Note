##### 内置函数

```python
round(a, b)           # a 四舍五入到小数点后 b 位
type(a)               # 返回 a 的数据类型
isinstance(a, b)      # 判断 a 是否为数据类型 b
len(a)                # 返回 a 的长度
enumerate(list)       # 枚举，返回 (index, value)
zip(list_1, list_2)   # 将相同位置元素组合成元组
```

##### math 库

```python
math.floor()     # 向下取整
math.ceil()      # 向上取整
```

##### numpy 库

```python
np.max(list)       # 返回最大值
np.argmax(list)    # 返回最大值位序
```
