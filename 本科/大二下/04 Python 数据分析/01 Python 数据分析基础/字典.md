##### 定义

存放无序的键/值（key/value）映射类型数据的容器

##### 常用操作

```python
dict.pop(a) / del dict[a]       # 删除键 a 及其值
a in dict                       # 判断键 a 是否存在
dict.get(a, b)                  # 返回键 a 的值，若无则返回 b（默认 None）
dict.keys()                     # 返回所有键
dict.values()                   # 返回所有值
dict.items()                    # 返回所有键和值
dict.clear()                    # 清空字典
```
