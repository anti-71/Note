##### 定义

一种不同数据类型元素的有序集合

##### 常用操作

```python
list.extend(list_1)        # 往末尾添加 list_1 中的元素
list.append(list_1)        # 将 list_1 作为元素添加到末尾
list.pop()                 # 移出末尾元素，可加位序指定删除
del list                   # 删除整个列表（也可删除指定元素）
list.count(a)              # 返回元素 a 的个数
list.index(a)              # 返回第一个 a 的位序
list.insert(index, a)      # 将 a 放入指定位序
list.remove(a)             # 移出第一个 a
list.reverse()             # 反向存放
max(list)                  # 返回最大元素
len(list)                  # 返回元素个数
list_1 + list_2            # 列表拼接
list * 2                   # 列表复制
```
