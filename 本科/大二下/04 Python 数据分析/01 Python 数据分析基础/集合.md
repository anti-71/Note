##### 定义

一系列无序的、不重复的组合体

##### 常用操作

```python
set.add(a)                                              # 添加元素 a
set.remove(a)                                           # 移出元素 a
set_1 <= set_2 / set_1.issubset(set_2)                  # 判断子集
set_1 - set_2 / set_1.difference(set_2)                 # 差集
set_1 | set_2 / set_1.union(set_2)                      # 并集
set_1 & set_2 / set_1.intersection(set_2)               # 交集
set_1 ^ set_2 / set_1.symmetric_difference(set_2)       # 对称差集
```
