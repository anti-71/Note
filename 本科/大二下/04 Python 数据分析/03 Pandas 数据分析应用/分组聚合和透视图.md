##### 数据排序

```python
np.sum(df.isnull(), axis=0)                    # 统计每列缺失值个数
df.sort_values(列标签, ascending=True,
               na_position='last', inplace=True) # 排序
```

##### 分组聚合

```python
grouped = df.groupby(by=列标签)                 # 分组
grouped.cumcount()                             # 每个组从 0 开始标值
grouped.agg([np.mean, np.sum])                 # 多个聚合函数
grouped.agg({列1: np.sum, 列2: np.mean})       # 不同列不同函数
grouped.apply(np.sum, axis=0)                  # 自定义函数
```

##### 透视图和交叉表

```python
pd.pivot_table(data=df, index, columns, values,
               aggfunc, fill_value=0, margins=True)

pd.crosstab(index=df[列1], columns=df[列2],
            normalize='all', margins=True)     # 交叉表
```

`normalize`：`all` 除以总数，`index` 按行，`columns` 按列
