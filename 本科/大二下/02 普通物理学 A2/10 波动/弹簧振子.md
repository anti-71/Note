##### 运动学量

| 物理量 | 公式 |
|:--|:--|
| 位移 | $x(t) = A\cos(\omega t + \phi)$ |
| 速度 | $v(t) = -A\omega\sin(\omega t + \phi)$ |
| 加速度 | $a(t) = -A\omega^2\cos(\omega t + \phi)$ |

##### 特征量

| 物理量 | 公式 |
|:--|:--|
| 角频率 | $\omega = \sqrt{\dfrac{k}{m}}$ |
| 周期 | $T = 2\pi\sqrt{\dfrac{m}{k}}$ |
| 频率 | $f = \dfrac{1}{2\pi}\sqrt{\dfrac{k}{m}}$ |
| 振幅 | $A = \sqrt{x_0^2 + (\dfrac{v_0}{\omega})^2}$ |
| 初相位 | $\phi = \tan^{-1}(-\dfrac{v_0}{\omega x_0})$ |

##### 能量

- 动能：$K = \dfrac{1}{2}mv^2 = \dfrac{1}{2}mA^2\omega^2\sin^2(\omega t + \phi)$
- 势能：$U = \dfrac{1}{2}kx^2 = \dfrac{1}{2}kA^2\cos^2(\omega t + \phi)$
- 总能量守恒：$E = K + U = \dfrac{1}{2}kA^2$
