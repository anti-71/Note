##### 布局管理器概述

布局管理器（Layout Manager）控制容器中组件的排列和大小，避免手动设置每个组件的位置

##### FlowLayout

按水平方向从左到右排列组件，一行排满自动换行，默认居中对齐

```java
frame.setLayout(new FlowLayout());
```

##### BorderLayout

将容器分为东、南、西、北、中五个区域，每个区域只能添加一个组件

```java
frame.setLayout(new BorderLayout());
frame.add(new JButton("North"), BorderLayout.NORTH);
frame.add(new JButton("Center"), BorderLayout.CENTER);
```

##### GridLayout

将容器划分为等大小的网格，所有组件大小相同

```java
frame.setLayout(new GridLayout(2, 3)); // 2行3列
```

##### BoxLayout

沿单一轴线（X 轴或 Y 轴）排列组件

```java
JPanel panel = new JPanel();
panel.setLayout(new BoxLayout(panel, BoxLayout.Y_AXIS));
panel.add(new JButton("Button 1"));
panel.add(Box.createVerticalStrut(10)); // 垂直间隔
```
