##### Thread 常用方法

| 方法 | 说明 |
|:--|:--|
| `public void run()` | 线程的任务方法 |
| `public void start()` | 启动线程 |
| `public String getName()` | 获取线程名称（默认 `Thread-索引`） |
| `public void setName(String name)` | 设置线程名称 |
| `public static Thread currentThread()` | 获取当前执行线程对象 |
| `public static void sleep(long millis)` | 让当前线程休眠指定毫秒 |
| `public final void join()` | 让调用此方法的线程先执行完 |

##### Thread 常见构造器

| 构造器 | 说明 |
|:--|:--|
| `public Thread(String name)` | 创建线程并指定名称 |
| `public Thread(Runnable target)` | 封装 `Runnable` 对象 |
| `public Thread(Runnable target, String name)` | 封装 `Runnable` 并指定名称 |

##### 代码示例

```java
Thread t1 = new MyThread("1号线程");
t1.start();
System.out.println(t1.getName()); // Thread-索引

Thread m = Thread.currentThread(); // 主线程
m.setName("主线程");
System.out.println(m.getName()); // main

// 休眠
Thread.sleep(1000);

// 插队
t1.join(); // 让 t1 先执行完
```
