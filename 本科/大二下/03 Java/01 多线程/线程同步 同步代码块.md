##### 作用

把访问共享资源的核心代码上锁，保证线程安全

##### 原理

每次只允许一个线程加锁后进入，执行完毕后自动解锁，其他线程才能进来

##### 注意事项

- 同步锁必须是**同一把锁**（同一个对象）
- 建议使用共享资源作为锁对象
- 实例方法建议用 `this` 作为锁对象
- 静态方法建议用 `类名.class` 作为锁对象

##### 代码

```java
public void drawMoney(double money) {
    String name = Thread.currentThread().getName();
    synchronized (this) {
        if (this.money >= money) {
            System.out.println(name + "取钱成功");
            this.money -= money;
        } else {
            System.out.println(name + "取钱失败");
        }
    }
}
```
