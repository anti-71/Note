##### 作用

把访问共享资源的核心方法上锁，保证线程安全

##### 原理

每次只能一个线程进入，执行完毕后自动解锁

##### 底层机制

- 实例方法：默认用 `this` 作为锁对象
- 静态方法：默认用 `类名.class` 作为锁对象

##### 代码

```java
public synchronized void drawMoney(double money) {
    String name = Thread.currentThread().getName();
    if (this.money >= money) {
        System.out.println(name + "取钱成功");
        this.money -= money;
    } else {
        System.out.println(name + "取钱失败");
    }
}
```

##### 同步代码块 vs 同步方法

| 对比 | 同步代码块 | 同步方法 |
|:--|:--|:--|
| 锁范围 | 小 | 大 |
| 可读性 | 一般 | 更好 |
