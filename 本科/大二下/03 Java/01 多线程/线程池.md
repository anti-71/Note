##### 线程池概述

线程池是一个可以复用线程的技术

**不使用线程池的问题**：每个请求都创建新线程，开销大，系统性能受严重影响

##### 创建方式一：ThreadPoolExecutor

```java
ThreadPoolExecutor pool = new ThreadPoolExecutor(
    3,  // corePoolSize: 核心线程数
    5,  // maximumPoolSize: 最大线程数
    10, // keepAliveTime: 临时线程存活时间
    TimeUnit.SECONDS,
    new ArrayBlockingQueue<>(3), // 任务队列
    Executors.defaultThreadFactory(),
    new ThreadPoolExecutor.AbortPolicy() // 拒绝策略
);
```

##### 创建方式二：Executors 工具类

| 方法 | 说明 |
|:--|:--|
| `newFixedThreadPool(n)` | 固定线程数量 |
| `newSingleThreadExecutor()` | 单线程 |
| `newCachedThreadPool()` | 按需创建 |
| `newScheduledThreadPool(n)` | 可延迟/定期执行 |

##### 常用方法

| 方法 | 说明 |
|:--|:--|
| `execute(Runnable)` | 执行 Runnable 任务 |
| `submit(Callable)` | 执行 Callable 任务，返回 Future |
| `shutdown()` | 等待任务完毕后再关闭 |
| `shutdownNow()` | 立即关闭 |

##### 注意事项

- 核心线程忙 + 队列满时，才创建临时线程
- 核心线程 + 临时线程都忙 + 队列满时，新任务被拒绝

##### 任务拒绝策略

| 策略 | 说明 |
|:--|:--|
| `AbortPolicy` | 抛异常（默认） |
| `DiscardPolicy` | 丢弃，不抛异常 |
| `DiscardOldestPolicy` | 抛弃队列中等待最久的 |
| `CallerRunsPolicy` | 由主线程直接执行 |
