##### try-catch-finally

`finally` 中的代码无论是否出现异常都会执行，适合释放资源

```java
InputStream is = null;
OutputStream os = null;
try {
    is = new FileInputStream("src.txt");
    os = new FileOutputStream("dest.txt");
    // 操作流
} catch (Exception e) {
    e.printStackTrace();
} finally {
    if (os != null) try { os.close(); } catch (Exception e) { }
    if (is != null) try { is.close(); } catch (Exception e) { }
}
```

##### try-with-resource（JDK 7+）

资源使用完毕后自动调用 `close()`，无需手动释放

```java
try (
    InputStream is = new FileInputStream("src.txt");
    OutputStream os = new FileOutputStream("dest.txt");
) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = is.read(buffer)) != -1) {
        os.write(buffer, 0, len);
    }
} catch (Exception e) {
    e.printStackTrace();
}
```

`()` 中只能放置实现了 `AutoCloseable` 接口的资源对象
