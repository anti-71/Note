##### IO 流

- **I**（Input）：输入流，把数据读到内存
- **O**（Output）：输出流，把数据写出去

##### 分类

| 分类标准 | 类型 |
|:--|:--|
| 流方向 | 输入流、输出流 |
| 流内容 | 字节流（所有文件）、字符流（纯文本） |

##### IO 流体系

- 字节输入流（`InputStream`）
- 字节输出流（`OutputStream`）
- 字符输入流（`Reader`）
- 字符输出流（`Writer`）
