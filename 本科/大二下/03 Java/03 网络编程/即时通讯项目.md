##### 需求

登录界面输入昵称，进入群聊窗口，实现在线聊天和实时显示在线人数

##### 服务端架构

```java
// 存储在线客户端
public static final Map<Socket, String> onLineSockets = new HashMap<>();

// 主线程接收连接
ServerSocket ss = new ServerSocket(Constant.PORT);
while (true) {
    Socket socket = ss.accept();
    new ServerReaderThread(socket).start();
}
```

##### 通信协议

| 类型编号 | 说明 |
|:--|:--|
| 1 | 登录消息，包含昵称 |
| 2 | 群聊消息，转发给所有在线客户端 |
| 3 | 私聊消息 |

##### 消息处理

```java
// ServerReaderThread
DataInputStream dis = new DataInputStream(socket.getInputStream());
int type = dis.readInt();
switch (type) {
    case 1:
        String nickName = dis.readUTF();
        Server.onLineSockets.put(socket, nickName);
        updateClientOnLineUserList(); // 刷新在线列表
        break;
    case 2:
        String msg = dis.readUTF();
        sendMsgToAll(msg); // 转发群聊消息
        break;
}
```
