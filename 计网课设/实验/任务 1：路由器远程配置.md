# 任务 1：路由器远程配置

## 一、目的和要求

**设计目的：**

使学生掌握路由器的几种常用配置方法，特别是通过**Console 线缆**（带外管理）和**Telnet**（带内管理）方式登录并管理路由器，熟悉不同命令行模式的切换 。

**实验背景**：

作为网络管理员，第一次在设备机房对路由器进行初次配置后，以后在办公室或者出差
时，也可以对设备进行远程管理，现在要在路由器上做适当配置。

## 二、实验环境

**软件环境**：

Cisco Packet Tracer 8.2。

**硬件设备：**

Router_2811 1台、PC 1台、交叉线（连接路由器与计算机）、标准Console配置线（连接PC串口与路由器Console口） 。

## 三、实验内容

### 第一步：拓扑搭建与初次连接

1. 使用**Console 线**连接PC的RS 232串口与路由器的Console接口 。
2. 在PC上打开“终端”（Terminal），建立连接。

### 第二步：基础信息配置

进入命令行界面进行如下配置：

```
Router> en                          # 进入特权模式
Router# conf t                      # 进入全局配置模式
Router(config)# hostname R1         # 更改主机名为 R1
R1(config)# enable secret 123456    # 设置进入特权模式的加密密码 
```

### 第三步：配置接口IP地址

```
R1(config)# interface fa 0/0        # 进入以太网接口
R1(config-if)# ip address 192.168.1.1 255.255.255.0  # 配置管理IP 
R1(config-if)# no shut              # 开启接口 
R1(config-if)# exit
```

### 第四步：配置Telnet远程登录密码

```
R1(config)# line vty 0 4            # 进入虚拟终端线路配置
R1(config-line)# password 20040804  # 设置Telnet登录密码
R1(config-line)# login              # 启用登录验证
R1(config-line)# exit
```

## 四、实验结果

**PC配置**：

将PC的IP设为192.168.0.1，网关设为192.168.0.254。

**连通性测试**：

在PC的“命令提示符”窗口中输入 `ping 192.168.0.254`，确保网络通畅。

**远程管理测试**：

在PC上执行`telnet 192.168.0.1`，根据提示输入Telnet密码和特权密码，成功进入路由器管理界面即表示配置成功。
