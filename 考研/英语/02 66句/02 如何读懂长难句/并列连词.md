- **and** ; **but** ; **or** ; **so** ; **for** ;
- **not only** … **but also** …; **either** … **or** …; **neither** … **nor** …;
- **not** … **but** …; **both** … **and** …

> [!warning] 注意
> 并列连词需要并列前后 **平行对称** 的内容，即连接 **对等** 的单词、短语或句子！
