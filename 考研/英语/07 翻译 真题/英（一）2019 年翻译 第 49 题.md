##### 题目

> [!question]
> This would be reasonable if it were not for the fact that scientists can easily arrange to cite themselves in their future publications, or get associates to do so for them in return for similar favours.

##### 一刷

如果不是为了事实：科学家们可以轻易地去引用他们自己的论文在他们未来的出版物里，或者找到伙伴去这样做是为了他们而不是为了相似的喜好，这将是合理的。

##### 评分

得分：0.5 / 2

- `cite themselves in their future publications` → “引用他们自己的论文在他们未来的出版物里” ✓
- `if it were not for the fact that` → “如果不是为了事实” 表述生硬，应为 **“如果不是因为/若不是”**
- `get associates to do so` → “找到伙伴去这样做” 不准确，`get sb. to do sth.` 意为 **“让/请某人做某事”**
- `in return for similar favours` → “而不是为了相似的喜好” 完全错误
  
  `in return for` 意为 **“作为……的回报”**，非 “而不是”
  
  全句应为 **“作为相似帮助的回报/互惠互利”**
- 整句因 `in return for` 理解相反导致后半句句义偏差
