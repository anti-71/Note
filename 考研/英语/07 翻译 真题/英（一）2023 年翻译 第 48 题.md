##### 题目

> [!question]
> Algorithms used to simulate human interactions are creating many of these concerns, especially as no-one is quite sure what the outcomes of using AI to interact with customers will be.

##### 一刷

用来模拟人类交流的算法造成了很多这样的担忧，特别是没人能确保使用人工智能与顾客交流的结果将会是怎样。

##### 评分

得分：1.0 / 2

- `Algorithms used to simulate...` → “用来模拟……的算法” ✓
- `creating many of these concerns` → “造成了很多这样的担忧” ✓
- `especially as no-one is quite sure` → “特别是没人能确保” 漏译 `as`（在……的情况下更是如此）
- `human interactions` → “人类交流” 可接受，**“人类互动”** 更准确
- `is quite sure` → “能确保” 不准确，应为 **“确定/确信”**（be sure ≠ ensure）

##### as 的知识点

> [!question] 
> 在阅读/翻译中见到 as 不知道如何翻译？

as 引导定语从句 / 引导状语从句 / 有时是介词 / 有时是副词

- **常规**： as 作连词 / 介词
- **特殊**： 不需要考虑词性

1. **As** we all know, learning English is important.（**正如**）
2. The house is **as** tall **as** the tree.（**和……一样**）
3. Tired **as** he was, he went on working.（**尽管**）

as 引导状语从句（翻译为"尽管"）必须使用倒装句型
