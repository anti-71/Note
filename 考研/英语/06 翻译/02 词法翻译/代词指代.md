##### 翻译方法

1. **直接译为代词** — 无歧义时，直接译为代词
2. **还原指代** — 若直译代词有 **歧义**，则要找出具体指代的名词，将其还原

##### 代词指代原则

1. **就近原则** — 代词一般位于所指代的内容之后，在寻找代词所指代的具体内容时，需要由近及远在上文寻找答案
2. **语法及语义一致原则** — 个别代词所指代的内容与代词相距较远，此时可根据语法及语义来判断代词所指代的内容

> [!tip] 翻译中代词较多为了避免重复，可以用"其"来替代

##### 真题讲解

###### 例 1 him 直译为代词"他"

> [!question]
> What is an intellectual? I shall define **him** as an individual who has elected as his primary duty and pleasure in life the activity of thinking in a Socratic way about moral problems.

| 处理方式 | 说明 |
|---|---|
| 我将 **他** 定义为… | 允许，参考译文如此 |
| 我将 **他（知识分子）** 定义为… | 允许，加注说明 |
| 我将 **知识分子** 定义为… | 允许，直接还原 |

###### 例 2 it 直译为代词"它"

> [!question]
> A sacred place of peace, however crude **it** may be, is a distinctly human need, as opposed to shelter, which is a distinctly animal need.

**译文：** 一个神圣的安宁的地方，无论 **它** 多么简陋…

> [!note] 
> - crude 形容人时意为"粗鲁的"，形容地方时意为"粗糙的 / 简陋的"
> - peace 可译作"和平 / 平静 / 安静 / 安宁 / 宁静"

###### 例 3 them / they 指代 cars

> [!question]
> There will be television chat shows // hosted by robots, and cars // with pollution monitors // **that** will disable **them** when **they** offend.

| 版本     | 译文                                                                          |
| ------ | --------------------------------------------------------------------------- |
| 翻译 1.0 | 将有（被机器人主持的）电视聊天节目，和（有（将 **它们** 残疾 // 当 **它们** 冒犯的时候）的污染监控器的）汽车              |
| 翻译 2.0 | 将有（被机器人主持的）电视聊天节目，和（有污染监控器的）汽车，当 **它们** offend 的时候，这（污染监控器）将 disable **它们** |
| 翻译 3.0 | 将有（被机器人主持的）电视聊天节目，和（有污染监控器的）汽车，当 **汽车** 违规排污时，污染监控器将 **使汽车无法行驶**            |
| 翻译 4.0 | 届时，将会出现由机器人主持的电视聊天节目，和装有污染监控器的汽车，当汽车违规排污时，污染监控器将使汽车无法行驶                     |

> [!tip] 本句涉及翻译技巧：词义选择 / 代词指代 / 词性转变 / 被动语态 / 定语从句 / 时态
> there be 译作 "有 / 存在"
