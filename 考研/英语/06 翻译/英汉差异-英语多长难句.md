##### 英语多长难句，汉语多简单句

> [!tip] **英译汉技巧：多加逗号**

英语擅长通过连接词和从句构成长句，汉语则习惯用短句表达

###### 示例

> [!quote] Plastics is made from water // which is a natural resource inexhaustible and available everywhere, // coal // which can be mined through automatic and mechanical processes at less cost // and lime // which can be obtained from the calcinations of limestone widely present in nature.

**译文：**

塑料是由水、煤、石灰制成。水是取之不尽、可以随处获得的资源；煤可以以较低的成本，通过自动化和机械化进行开采；石灰可以通过自然界广泛存在的石灰石进行煅烧得到。
