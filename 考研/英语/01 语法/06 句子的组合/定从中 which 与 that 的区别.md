which 指物，that 指物又可指人

##### 当 which 与 that 都指物时的区别

| 场景        | 区别                   |
| --------- | -------------------- |
| 只能用 that  | 代 高 序 双 特            |
| 只能用 which | 1. 有 “，” <br>2. 介词之后 |

- **代**：先行词为不定代词（如 all, anything, everything, nothing 等）
    
	> [!example] 
> There is nothing that I’m worried about.
    
- **高**：先行词被最高级修饰
    
    > [!example] 
> The most important thing that we learn is……
    
- **序**：先行词被序数词修饰
    
    > [!example] 
> I like the second football match that was held last week.
    
- **双**：先行词既有人又有物（并列人和物）
    
    > [!example] 
> We are talking the piano and the pianist that were in the concert.
    
- **特**：先行词被特殊词修饰（如 the only, the very, just the 等）
    
    > [!example] 
> There is the only thing that I can do.
