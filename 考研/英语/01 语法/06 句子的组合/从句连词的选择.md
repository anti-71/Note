**从句类型不同时，即使从句一样，连词也不一定相同**

##### 连词选择二步法

1. 判断从句类型
2. 看从句是否完整或看从句缺什么

| 第一步：<br><br>判类型       | 名词性从句<br>（主从、宾从、表从、同从）                     | 定语从句                                                    |
| :-------------------- | :----------------------------------------- | :------------------------------------------------------ |
| **第二步：<br><br>从句缺什么** | 从句主干完整 … that “无意义”<br><br>**宾从 that 可省略** | 从句缺 S./O./P. … that/which/who/whom<br>**做从句宾语都可省略**     |
|                       | 从句完整 … whether/if “是否”                     | 从句缺定语 … whose                                           |
|                       | 从句缺 S./O./P. … what (物)/who (人)/whom (人)   | 从句缺状语 … when/where/why<br>或介词 + which/whom<br>（注：as 另讲） |
|                       | 从句缺状语 … when/where/how/why                 |                                                         |
