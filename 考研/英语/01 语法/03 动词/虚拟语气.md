##### 1）If 条件虚拟语气

| 时间 | If 条件从句           | 主句                                 |
| ---- | --------------------- | ------------------------------------ |
| 现在 | were/did              | would (could/might/should) do        |
| 过去 | had done              | would (could/might/should) have done |
| 将来 | were to do; should do | would (could/might/should) do        |

**难点：**

1. **时态倒退**：过去的事情（历史）是已经发生过的，是事实！！！是不可以被假设的！如果非要对过去的事情假设，那就是虚拟语气了！

2. **be 用 were**：标记性语言需要标记来体现这种非事实状态

 > [!example]
> If he were here, I would see him. 他现在若是在这里，我就会去看他（他现在不在这里）

- **现在**：if 从句（**were/did**），**主句**（**would/could/might/should do**）

> [!example]
> 事实：I am not a bird. I can not fly in the sky.
>
> 虚拟：If I **were** a bird, I **would fly** in the sky.

- **过去**：if 从句（**had done**），**主句**（**would/could/might/should have done**）

> [!example]
>
> 事实：He did not know her. He did not greet her.
>
> 虚拟：**If** he **had known** her, he **would have greeted** her.

- **将来**：if 从句（**were to do/should do**），**主句**（**would/could/might/should do**）

> [!example]
> If I **should win** the lottery, I **would travel** the world.（可能性极低）
>
> If the sun **were to rise** in the west, I **would change** my mind.（几乎不可能）

> [!note]
>
> - should do：不太可能实现，但万一实现呢？表希望实现！
> - were to do：绝无可能实现！

> [!info] 主将从现
>
> | 引导词             | 从句时态        | 主句时态        | 例句                                | 翻译               |
> | ------------------ | --------------- | --------------- | ----------------------------------- | ------------------ |
> | if（如果）         | 现在时（do/be） | will/can + 动原 | If it rains, we'll cancel.          | 下雨就取消。       |
> | as long as（只要） | 现在时（do/be） | will/can + 动原 | As long as you try, you'll succeed. | 只要努力就会成功。 |
> | when（当… 时）     | 现在时（do/be） | will/can + 动原 | When she arrives, we'll start.      | 她到了我们就开始。 |
>
> **原因：**
>
> 从句引导词（条件 / 时间触发点）if /as long as /when 等自带 “**不确定**” 性，也就是说已经交代了这是一种 “**可能性**”，所以从句中用 **事实语气** 表述，再不用 “**情态动词 + 动词原形**” 这种不确定语气了，不然就成了 **重复交代** 了！
>
> > [!example] 类似
> >
> > - I guess he **arrives** tomorrow.（对）
> > - I guess he **will arrive** tomorrow.（错 —— 重复交代）

###### if 省略倒装的情况

| 假设类型       | 正常语序 (If ...)                                            | 倒装语序 (省略 if)                                           |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 与现在事实相反 | If + 主语 + were + ...<br />If I **were** you, I would go.   | Were + 主语 + ...<br />**Were** I you, I would go.           |
| 与过去事实相反 | If + 主语 + had + 过去分词 + ...<br />If you **had** studied, you would have passed. | Had + 主语 + 过去分词 + ...<br />**Had** you studied, you would have passed. |
| 与将来事实相反 | If + 主语 + should + 动词原形 + ...<br />If it **should** rain, we will stay. | Should + 主语 + 动词原形 + ...<br />**Should** it rain, we will stay. |
| 与将来事实相反 | If + 主语 + were to + 动词原形 + ...<br />If I **were** to fail, I would try again. | Were + 主语 + to + 动词原形 + ...<br />**Were** I to fail, I would try again. |

**关键点总结：**

1. **触发词**：只有 were, should, had 这三个词可以触发倒装（did 不能）
2. **结构变化**：将这三个词直接提到句首，if 即可省略，句子其余部分的语序不变
3. **语气**：倒装结构的语气比正常语序更加正式、书面化

##### 2）同 if 条件虚拟语气

- **as if / as though** + 主干 = **if** + 主干（从句）
- **wish that** + 主干 = **if** + 主干（从句）
- **If only** + 主干 = **if** + 主干（从句）
- **would rather that** + 主干 = **if** + 主干（从句）

> [!example]
> She speaks English so fluently [**as if / as though** she **were** a native speaker].

###### 含义

- **as if / as though** + 主干（假设或比喻 ——**非事实语气**）
- **wish that** + 主干（强烈愿望 ——**希望成真**）
- **If only** + 主干（强烈愿望 ——**希望成真**）
- **would rather that** + 主干（强烈愿望 ——**希望成真**）

三个表示强烈愿望的词 / 词组：

- wish（真希望）；If only（要是…… 该多好）；would rather（宁愿）**暗含明知不可能！**

###### 用法

和 if 大体相同

| 表达                | 虚拟时间    | 从句结构               | 极简例句                                      |
| ----------------- | ------- | ------------------ | ----------------------------------------- |
| as if / as though | 现在      | 过去式（be 用 were）     | He acts as if he knew everything.         |
|                   | 过去      | had + 过去分词         | She looks as though she had seen a ghost. |
| wish / if only    | 现在      | 过去式（be 用 were）     | I wish I were taller.                     |
|                   | 过去      | had + 过去分词         | If only I had studied harder.             |
|                   | 将来      | would/could + 动词原形 | I wish the rain would stop.               |
| would rather      | 现在 / 将来 | 过去式（be 用 were）     | I'd rather you kept quiet.                |
|                   | 过去      | had + 过去分词         | I'd rather you hadn't told him.           |

1. as if/as though：无将来虚拟，现在 $\implies$ 过去式，过去 $\implies$ 过去完成时；
2. wish/if only：现在 / 过去同 as if，将来用 would/could + 动原（if only 语气更强）；
3. would rather：现在 / 将来 $\implies$ 过去式，过去 $\implies$ 过去完成时；

> [!example]
> I **wish** that we **were** both young again.（we are both old now）
>
> **If only** I **had not lied** to my parents!
>
> I **would rather** you **had not told** me about the news.

##### 3）代替 if 条件句的含蓄虚拟语气

| 表达          | 含义           | 例句                                           | 翻译                           |
| ------------- | -------------- | ---------------------------------------------- | ------------------------------ |
| **without**   | 没有（若没有） | Without your help, I wouldn’t finish it.       | 没有你的帮助，我完不成。       |
| **but for**   | 要不是         | But for the rain, we would go hiking.          | 要不是下雨，我们就去徒步了。   |
| **but**       | 要不是         | I would call him, but I don’t have his number. | 我会给他打电话，要不是没号码。 |
| **otherwise** | 否则           | I must hurry; otherwise, I would be late.      | 我得快点，否则会迟到。         |
| **or**        | 否则、要不然   | Hurry up, or you would miss the bus.           | 快点，否则赶不上公交。         |

有些句子里，没有 if，但是有 **without / otherwise / or / but for / but** 等，此时可把它们看做 **虚拟条件句**，然后根据时间，选择 **主句** 的动词形式

> [!example]
>
> - **Without** your help, I **wouldn’t have passed** the exam.
>
>   = **If** you hadn’t helped me, I wouldn’t have passed the exam.
>
>   = **But for** your help, I **wouldn’t have passed** this exam.
>
> - I didn’t have your telephone number; **otherwise, **/** or** I **would have called** you back.
>
>   = If I **had had** your number, I **would have called** you back.

###### 用法

- without

- but for “要不是”

- or “否则”

- otherwise,

- but


→ 现在，**would (could/might/should) do**

→ 过去，**would (could/might/should) have done**

→ 将来，**would (could/might/should) do**

> [!example]
> Without water, there **could be** no life.
>
> But for your cooperation, we **wouldn’t have done** the work so well.
>
> He **would put** on weight, but he doesn’t eat much.
>
> 他本来是会发胖的，但是他特别注意节食。

##### 4）命令建议（希望成真）

| 类型                     | 核心表达（代表性词汇）                                       | 从句结构                               | 例句                                                         |
| ------------------------ | ------------------------------------------------------------ | -------------------------------------- | ------------------------------------------------------------ |
| **建议 / 命令 / 要求类** | suggest/advise/order/demand/<br />insist/request/urge/recommend | (should) + 动原（should 可省）         | He suggests we (should) start early.<br />他建议我们早点出发。 |
| **情感评价 / 必要性类**  | it’s necessary/important/strange/a pity/natural              | (should) + 动原（should 可省）         | It’s necessary we (should) prepare.<br />我们有必要准备一下。 |
| **时间建议类**           | it’s time (that)/it’s high time (that)                       | 过去式 /should + 动原（should 不可省） | It’s high time we solved the problem.<br />早就该解决这个问题了。 |

> [!example] 
> It is time that you **should go** to bed.
> 
> It is time that you **went** to bed.

###### 代表性词汇

一坚持 insist

二命令 order, command

四建议 advise, consider, suggest, recommend

四要求 require, request, demand, desire/ask

> [!example] 
> His father **ordered** that he (should) go to bed at 10 o’clock.（should 可省，不可换）

以上词法构成的派生词，引出的名词性从句：

> [!example] 
> 1. My advice is that……（表从）
> 
> 2. This is my suggestion that ……（同位从）
> 
> 3. It is demanded that……（主从）
> 
> 4. He insisted that……（宾从）
> 
> → + (should) + 原形
> 
> The teacher gave **order** that the test (should) be finished before 7:30.

###### It is adj. that 从句

表示 “有必要的” 形容词，修饰 that 从句时，该从句亦须使用助动词 should，而 should 可省

此类形容词通常有 necessary (有必要的)、important (重要的)、essential (不可或缺的)、urgent (紧急的)、desirable (可取的)、recommendable (值得推荐的)、advisable (明智的)、crucial（至关重要的）……

> [!example] 
> It is **necessary** that he (should) work hard. 他必须努力工作。
> 
> If we are ever going to protect the atmosphere, it is **crucial** that those new plants (should) be environmentally sound.
> 
> 若想切实保护大气环境，这些新建工厂必须达到环保标准，这一点至关重要。
