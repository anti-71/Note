# 第五节 句式结构的组成

## 一、主干部分

任何句子的主干都是简单句，英语语法中，简单句分为五种类型

| 句型                                                     | 例句                    |
| :----------------------------------------------------- | :-------------------- |
| **主语 + 谓语**（S+V）                                       | I will leave.         |
| **主语 + 谓语 + 宾语**（S+V+O）                                | I love you.           |
| **主语 + 谓语 + 宾语 + 宾补**（S+V+O+OC）                        | Love makes you crazy. |
| **主语 + 谓语 + 宾语 1 + 宾语 2**（S+V+O+O）                     | I give you a book.    |
| **主语 + 谓语 + 主补**（S+V+SC）/<br>**主语 + 系动词 + 表语**（S+系V+P） | I am a student.       |

> [!note] 
> 有的语法书将 there be 句型作为一种特殊句型，从主系表结构中拆分出来，将其作为第六种句子类型
