### 五、例题

#### 方程求解

判别类型、选择方法、求解

##### 例 1

> 微分方程$ ydx + (x - 3y^2)dy = 0 $满足条件$ y|_{x = 1} = 1 $的解为$ y =\underline{\quad\quad}$ 

**法一**

由$ ydx + (x - 3y^2)dy = 0 $知
$$
 y\frac{dx}{dy} + x - 3y^2 = 0, 
$$
即$\frac{dx}{dy} + \frac{x}{y} = 3y$

由线性方程通解公式得
$$
 \begin{align*} x&=e^{-\int\frac{1}{y}dy}\left[\int 3y e^{\int\frac{1}{y}dy}dy + C\right]\\ &=\frac{1}{y}\left[\int 3y^2 dy + C\right]\\ &= y^2 + \frac{C}{y} \end{align*} 
$$
由$ y|_{x = 1} = 1 $可知$ C = 0 $，则$ x = y^2 $，$ y = \pm\sqrt{x} $ 

由$ y|_{x = 1} = 1 $可知，$ y = \sqrt{x} $

**法二**

由$ ydx + (x - 3y^2)dy = 0 $知
$$
(ydx + xdy) - 3y^2 dy = 0,
$$
即$ d(xy) - dy^3 = 0 $，**分组凑微分**
$$
d(xy - y^3) = 0, \\ xy - y^3 = C
$$
由$ y|_{x = 1} = 1 $知$ C = 0 $，则$ y = \sqrt{x} $

##### 例 2

> 已知$ y_1 = e^{2x} - xe^{2x} $，$ y_2 = e^x - xe^{2x} $，$ y_3 = -xe^{2x} $是某二阶常系数非齐次线性微分方程的 3 个解，则该方程的通解为$ y = \underline{\quad\quad}$

如果$y_1^*(x), y_2^*(x)$是非齐次方程的两个特解，则$y(x) = y_2^*(x) - y_1^*(x)$是齐次微分方程的解

由该结论去计算任意两个特解的差，
$$
y_1-y_3=e^{3x},\\
y_2-y_3=e^{x}
$$
由于$\frac{e^{3x}}{e^{x}}\not\equiv C$，二者线性无关，所以是该方程的两个齐次解，最后只需加上特解$y_3$，即方程的通解为
$$
y=C_1e^{3x}+C_2e^{x}-xe^{2x}
$$

#### 综合题

##### 例 3

> 设函数$ f(x) $满足$ f(x + \Delta x) - f(x) = 2xf(x)\Delta x + o(\Delta x)(\Delta x \to 0) $，且$ f(0) = 2 $，则$ f(1) = \underline{\quad\quad}$

**法一** 

**导数定义**

由$ f(x + \Delta x) - f(x) = 2xf(x)\Delta x + o(\Delta x)(\Delta x \to 0) $ 知
$$
 \frac{f(x + \Delta x) - f(x)}{\Delta x} = 2xf(x) + \frac{o(\Delta x)}{\Delta x}
$$
上式中令$ \Delta x \to 0 $ 得
$$
 f'(x) = 2xf(x)
$$
解方程得
$$
 f(x) = Ce^{x^2}
$$
又$ f(0) = 2 $，则$ C = 2 $，$ f(x) = 2e^{x^2} $，$ f(1) = 2e $

**法二**

**微分定义**

对照微分的定义
$$
\Delta y=A\Delta x+o(\Delta x)
$$
即$dy=Adx$，由$ f(x + \Delta x) - f(x) = 2xf(x)\Delta x + o(\Delta x)(\Delta x \to 0) $ 知
$$
dy=2xf(x)dx
$$
可以更快得出微分方程

##### 例 4

> 设函数$ f(x) $连续，且满足
> $$
>  \int_{0}^{x} f(x - t)dt = \int_{0}^{x} (x - t)f(t)dt + e^{-x} - 1
> $$
> 求$ f(x) $的表达式

令$ u = x - t $，则$ \int_{0}^{x} f(x - t)dt = \int_{0}^{x} f(u)du $。

由题设知
$$
\int_{0}^{x} f(u)du = x\int_{0}^{x} f(t)dt - \int_{0}^{x} tf(t)dt + e^{-x} - 1
$$
两端求导得$ f(x) = \int_{0}^{x} f(t)dt - e^{-x} $，且$ f(0) = -1 $

因此$ f'(x) - f(x) = e^{-x} $

从而
$$
f(x) = e^{\int dx}\left( \int e^{-x} e^{-\int dx}dx + C \right) = Ce^{x} - \frac{e^{-x}}{2}
$$
由$ f(0) = -1 $，得$ C = -\frac{1}{2} $，所以$ f(x) = -\frac{e^{x} + e^{-x}}{2} $

#### 应用题

##### 例 5

> 设非负函数$ y = y(x)(x \geq 0) $满足微分方程 $ xy'' - y' + 2 = 0 $
>
> 当曲线$ y = y(x) $过原点时，其与直线$ x = 1 $及$ y = 0 $围成的平面区域$ D $的面积为 2，求$ D $绕$ y $轴旋转所得旋转体的体积

记$ y' = p $，则$ y'' = p' $，代入微分方程，当$ x > 0 $ 时，
$$
p' - \frac{1}{x}p = -\frac{2}{x}
$$
解得
$$
\begin{align*} y' = p &= e^{\int \frac{1}{x}dx} \left[ \int \left( -\frac{2}{x} \right) e^{-\int \frac{1}{x}dx}dx + C_1 \right] \\ &= x \left[ \int \left( -\frac{2}{x^2} \right) dx + C_1 \right] \\ &= 2 + C_1 x \end{align*}
$$
因此$ y = 2x + \frac{1}{2}C_1 x^2 + C_2 $，$ (x > 0) $

由已知$ y(0) = 0 $，有$ \lim_{x \to 0^+} y = 0 $，于是$ C_2 = 0 $，$ y = 2x + \frac{1}{2}C_1 x^2 $

由于$ 2 = \int_{0}^{1} \left( 2x + \frac{1}{2}C_1 x^2 \right) dx = 1 + \frac{1}{6}C_1 $，所以$ C_1 = 6 $，故
$$
 y = 2x + 3x^2
$$
故所求体积为$ V = 2\pi \int_{0}^{1} xy(x)dx = 2\pi \int_{0}^{1} (2x^2 + 3x^3)dx = \frac{17\pi}{6} $
