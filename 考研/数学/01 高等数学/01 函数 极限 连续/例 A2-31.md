> [!question] 
> 设 $x_1 = \sqrt{6}, x_2 = \sqrt{6 + \sqrt{6}}, \cdots, x_n = \sqrt{6 + \sqrt{6 + \sqrt{6 + \cdots + \sqrt{6}}}}$，求极限 $\lim_\limits{n \to \infty} x_n$

**法一**

$x_{n+1} = \sqrt{6 + x_n}$，令 $f(x) = \sqrt{6 + x}$，由于 

$$
f'(x) = \frac{1}{2\sqrt{6 + x}} > 0
$$

，则 $f(x)$ 单调增加，又 $x_1 < x_2$，则 $\{x_n\}$ 单调增加

又 $x_1 = \sqrt{6} < 3$ （3 是在草稿纸上求出的极限），若 $x_n < 3$，则 $x_{n+1} = \sqrt{6 + x_n} < 3$，从而 $x_n < 3$（归纳法），即数列 $\{x_n\}$ 上有界，则 $\lim_\limits{n \to \infty} x_n$ 存在

设 $\lim_\limits{n \to \infty} x_n = a$，由于 $0 < x_n < 3$，故由[[保号性|极限的保序性]]知，$0 \leqslant a \leqslant 3$ 

$x_{n+1} = \sqrt{6 + x_n}$ 两端取极限知，$a = \sqrt{6 + a}$，解得 $a = 3$，或 $a = -2$（舍去）

则 $\lim_\limits{n \to \infty} x_n = 3$

**法二**

直接证明 $\lim_\limits{n \to \infty} x_n = 3$

由 $x_{n+1} = \sqrt{6 + x_n}$ 知 
$$ 
\begin{aligned} |x_n - 3| &= \left|\sqrt{6 + x_{n-1}} - 3\right| \\&= \frac{|x_{n-1} - 3|}{\sqrt{6 + x_{n-1}} + 3} \\ &< \frac{1}{3}|x_{n-1} - 3| < \frac{1}{3^2}|x_{n-2} - 3| < \cdots < \frac{1}{3^{n-1}}|x_1 - 3| \to 0 \quad (n \to \infty) \end{aligned} 
$$ 
则 $\lim_\limits{n \to \infty} x_n = 3$
