##### 多元积分应用一览表

| **物理量 \ 积分类型** | **平面薄板 (D)**                                                      | **空间几何体 (Ω)**                                                      | **空间曲线段 (C)**                                        | **空间曲面片 (Σ)**                                                     |
| -------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------- | ----------------------------------------------------------------- |
| **几何度量**       | 面积：<br>$A = \displaystyle\iint_\limits{D} \mathrm{d}\sigma$       | 体积：<br>$V = \displaystyle\iiint_\limits{\Omega} \mathrm{d}V$       | 弧长：<br>$s = \displaystyle\int_{C} \mathrm{d}s$       | 面积：<br>$S\displaystyle = \iint_\limits{\Sigma} \mathrm{d}S$       |
| **质量 ($m$)**   | $\displaystyle\iint_\limits{D} \rho(x,y)\mathrm{d}\sigma$         | $\displaystyle\iiint_\limits{\Omega} \rho(x,y,z)\mathrm{d}V$       | $\displaystyle\int_{C} \rho(x,y,z)\mathrm{d}s$       | $\displaystyle\iint_\limits{\Sigma} \rho(x,y,z)\mathrm{d}S$       |
| **质心**         | $\dfrac{\displaystyle\iint_\limits{D} x\rho \mathrm{d}\sigma}{m}$ | $\dfrac{\displaystyle\iiint_\limits{\Omega} x\rho \mathrm{d}V}{m}$ | $\dfrac{\displaystyle\int_{C} x\rho \mathrm{d}s}{m}$ | $\dfrac{\displaystyle\iint_\limits{\Sigma} x\rho \mathrm{d}S}{m}$ |
| **形心**         | $\dfrac{\displaystyle\iint_\limits{D} x \mathrm{d}\sigma}{A}$     | $\dfrac{\displaystyle\iiint_\limits{\Omega} x \mathrm{d}V}{V}$     | $\dfrac{\displaystyle\int_{C} x \mathrm{d}s}{s}$     | $\dfrac{\displaystyle\iint_\limits{\Sigma} x \mathrm{d}S}{S}$     |
| **转动惯量**       | $\displaystyle\iint_\limits{D} y^2 \rho \mathrm{d}\sigma$         | $\displaystyle\iiint_\limits{\Omega} (y^2+z^2) \rho \mathrm{d}V$   | $\displaystyle\int_{C} (y^2+z^2) \rho \mathrm{d}s$   | $\displaystyle\iint_\limits{\Sigma} (y^2+z^2) \rho \mathrm{d}S$   |

##### 1）变力做功

- 力：$\boldsymbol{F} = P\boldsymbol{i} + Q\boldsymbol{j} + R\boldsymbol{k}$
- 功：$W = \displaystyle\int_{\overparen{AB}} P\mathrm{d}x + Q\mathrm{d}y + R\mathrm{d}z$

##### 2）通量

- 向量场：$\boldsymbol{U}(x,y,z) = P\boldsymbol{i} + Q\boldsymbol{j} + R\boldsymbol{k}$
- 通量：$\displaystyle\varPhi = \iint_\limits{\Sigma} P\mathrm{d}y\mathrm{d}z + Q\mathrm{d}z\mathrm{d}x + R\mathrm{d}x\mathrm{d}y$
