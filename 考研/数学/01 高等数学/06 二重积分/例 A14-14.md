> [!question] 
> 设 $f(t)$ 在 $[0,+\infty)$ 上连续，且满足 $f(t) = \mathrm{e}^{4\pi t^2} + \displaystyle\iint\limits_{x^2+y^2\leqslant 4t^2} f\left(\dfrac{1}{2}\sqrt{x^2+y^2}\right)\mathrm{d}x\mathrm{d}y$
> 
> 求 $f(t)$

回顾在定积分中，此类题一般是变上限积分求导，在此处，想办法转为定积分

观察到可以[[利用极坐标计算]]

$$\displaystyle\iint\limits_{x^2+y^2\leqslant 4t^2} f\left(\dfrac{1}{2}\sqrt{x^2+y^2}\right)\mathrm{d}x\mathrm{d}y = \int_{0}^{2\pi}\mathrm{d}\theta\int_{0}^{2t} f\left(\dfrac{1}{2}r\right)r\mathrm{d}r = 2\pi\int_{0}^{2t} r f\left(\dfrac{1}{2}r\right)\mathrm{d}r$$

则 $f(t) = \mathrm{e}^{4\pi t^2} + 2\pi\displaystyle\int_{0}^{2t} r f\left(\dfrac{1}{2}r\right)\mathrm{d}r$

两边对 t 求导

$$f'(t) = 8\pi t\mathrm{e}^{4\pi t^2} + 8\pi t f(t)$$

判断方程为[[线性方程]]，使用通解公式

$$f(t) = \mathrm{e}^{\int 8\pi t\mathrm{d}t}\left(\int 8\pi t\mathrm{e}^{4\pi t^2} \mathrm{e}^{-\int 8\pi t\mathrm{d}t}\mathrm{d}t + C\right) = (4\pi t^2 + C)\mathrm{e}^{4\pi t^2}$$

从题设中观察到 $f(0) = 1$

代入得 $C = 1$，因此

$$f(t) = (4\pi t^2 + 1)\mathrm{e}^{4\pi t^2}$$
