> [!question] 
> 求函数 $f(x,y) = xy(a-x-y)$ 的极值

求含参函数的极值，在[[无条件极值#求具有二阶连续偏导数的二元函数 $z = f(x,y)$ 极值的一般步骤|原有步骤]]的基础上需要对 a 讨论

求驻点，求 x 和 y 的偏导

$$ \begin{cases} f'_x(x,y) = y(a-x-y)-xy = 0, \\\\ f'_y(x,y) = x(a-x-y)-xy = 0 \end{cases} $$

得驻点 $(0,0),(0,a),(a,0),(\displaystyle\frac{a}{3},\frac{a}{3})$

利用[[无条件极值#定理（极值的充分条件）|极值的充分条件]]判定

$$A = \frac{\partial^2 f}{\partial x^2} = -2y,\ B = \frac{\partial^2 f}{\partial x\partial y} = a-2x-2y,\ C = \frac{\partial^2 f}{\partial y^2} = -2x$$

则

$$AC-B^2 = 4xy-(a-2x-2y)^2$$

计算各点的 $AC-B^2$ 的值：

$$
(0,0)=-a^2,\ (0,a)=-a^2,\ (a,0)=-a^2,\ (\frac{a}{3},\frac{a}{3})=\frac{a^2}{3}
$$

当 $a\neq0$ 时，前三个点不为极值点，$(\displaystyle\frac{a}{3},\frac{a}{3})$ 必为极值点

分类讨论

1.  $a>0$ 时

$\displaystyle(\frac{a}{3},\frac{a}{3})$ 为极大值点，$f(\displaystyle\frac{a}{3},\frac{a}{3}) = (\frac{a}{3})^3$

2. $a<0$ 时

$(\displaystyle\frac{a}{3},\frac{a}{3})$ 为极小值点，$\displaystyle f(\frac{a}{3},\frac{a}{3}) = (\frac{a}{3})^3$

3. $a=0$ 时

驻点减少到一个 $(0,0)$，而 $AC-B^2=0$；

$f(x,x)=-2x^3$ 可正可负，$f(0,0)=0$

则 $(0,0)$ 不是极值点
