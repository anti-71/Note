> [!question] 
> 设 $a_1 = a_2 = 1, a_{n+1} = a_n + a_{n-1} (n = 2,3,\cdots)$，试证：
> 
> $\displaystyle\sum_{n=1}^{\infty} a_n x^{n-1}$ 在 $\lvert x \rvert < \dfrac{1}{2}$ 处必收敛，并求其和函数

**证明**

要证明在 $\lvert x \rvert < \dfrac{1}{2}$ 处必收敛，即要求收敛域，但 $a_n$ 未显式给出，故先求 $a_n$

由 $a_1 = a_2 = 1$ 及 $a_{n+1} = a_n + a_{n-1}$，根据数学归纳法，知 $\{a_n\}$ 单调增加，即 $a_{n+1} > a_n$，则

$$ a_{n+1} = a_n + a_{n-1} < a_n + a_n = 2a_n < 2^2 a_{n-1} < \cdots < 2^{n-1} a_2 = 2^{n-1}, $$

从而有 $a_n < 2^{n-2}\ (n = 4,5,\cdots)$（$n=3$ 时取等），于是

$$\lvert a_n x^{n-1} \rvert < 2^{n-2} \lvert x^{n-1} \rvert = \dfrac{1}{2} \lvert (2x)^{n-1} \rvert$$

由于级数 $\displaystyle\sum_{n=1}^{\infty} (2x)^{n-1}$ 在 $\lvert x \rvert < \dfrac{1}{2}$ 时绝对收敛，则级数 $\displaystyle\sum_{n=1}^{\infty} a_n x^{n-1}$ 在 $\lvert x \rvert < \dfrac{1}{2}$ 处收敛

求和函数，令 $S(x) = \displaystyle\sum_{n=1}^{\infty} a_n x^{n-1} \left(x \in \left(-\frac{1}{2}, \frac{1}{2}\right)\right)$

我们想到用递推式代换，凑回 $S(x)$：先把不能用递推式的前两项拿出来

$$
S(x) = 1 + x + \sum_{n=3}^{\infty} a_n x^{n-1} 
$$

下标平移，凑出 $a_{n+1}$

$$ \begin{aligned} &= 1 + x + \sum_{n=2}^{\infty} a_{n+1} x^n \\&= 1 + x + \sum_{n=2}^{\infty} (a_n + a_{n-1}) x^n \\ &= 1 + x + x\left[S(x) - a_1\right] + x^2 S(x) \\&= 1 + (x + x^2)S(x), \end{aligned} $$

则

$$ S(x) = \frac{1}{1 - x - x^2}, \quad \lvert x \rvert < \frac{1}{2}$$
