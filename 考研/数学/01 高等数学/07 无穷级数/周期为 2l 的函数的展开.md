##### 1）$[-l,l]$ 上展开

$$
a_n = \frac{1}{l} \int_{-l}^{l} f(x)\cos \frac{n\pi x}{l} \, dx, \quad n = 0,1,2,\cdots, \\ b_n = \frac{1}{l} \int_{-l}^{l} f(x)\sin \frac{n\pi x}{l} \, dx, \quad n = 1,2,\cdots
$$

##### 2）$[-l,l]$ 上奇偶函数的展开

###### Ⅰ $f(x)$ 为奇函数

$$
 a_n = 0, \quad n = 0,1,2,\cdots, \\ b_n = \frac{2}{l} \int_{0}^{l} f(x)\sin \frac{n\pi x}{l} \, dx, \quad n = 1,2,\cdots
$$

###### Ⅱ $f(x)$ 为偶函数

$$
 a_n = \frac{2}{l} \int_{0}^{l} f(x)\cos \frac{n\pi x}{l} \, dx, \quad n = 0,1,2,\cdots, \\ b_n = 0, \quad n = 1,2,\cdots
$$

##### 3）在 $[0,l]$ 上展为正弦或展为余弦

###### Ⅰ 展为正弦

$$
a_n = 0, \quad n = 0,1,2,\cdots, \\ b_n = \frac{2}{l} \int_{0}^{l} f(x)\sin \frac{n\pi x}{l} \, dx, \quad n = 1,2,\cdots
$$

###### Ⅱ 展为余弦

$$
a_n = \frac{2}{l} \int_{0}^{l} f(x)\cos \frac{n\pi x}{l} \, dx, \quad n = 0,1,2,\cdots, \\ b_n = 0, \quad n = 1,2,\cdots
$$
