##### 1）$[-\pi,\pi]$ 上展开

$$
 a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x)\cos nx \, dx, \quad n = 0,1,2,\cdots, \\ b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x)\sin nx \, dx, \quad n = 1,2,\cdots
$$

##### 2）$[-\pi,\pi]$ 上奇偶函数的展开

###### Ⅰ $f(x)$ 为奇函数

$$
 a_n = 0, \quad n = 0,1,2,\cdots, \\ b_n = \frac{2}{\pi} \int_{0}^{\pi} f(x)\sin nx \, dx, \quad n = 1,2,\cdots
$$

###### Ⅱ $f(x)$ 为偶函数

$$
a_n = \frac{2}{\pi} \int_{0}^{\pi} f(x)\cos nx \, dx, \quad n = 0,1,2,\cdots, \\ b_n = 0, \quad n = 1,2,\cdots
$$

##### 3）在 $[0,\pi]$ 上展为正弦或展为余弦

###### Ⅰ展为正弦

$$
 a_n = 0, \quad n = 0,1,2,\cdots, \\ b_n = \frac{2}{\pi} \int_{0}^{\pi} f(x)\sin nx \, dx, \quad n = 1,2,\cdots
$$

###### Ⅱ 展为余弦

$$
 a_n = \frac{2}{\pi} \int_{0}^{\pi} f(x)\cos nx \, dx, \quad n = 0,1,2,\cdots, \\ b_n = 0, \quad n = 1,2,\cdots
$$
