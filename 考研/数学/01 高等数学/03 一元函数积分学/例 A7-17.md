> [!question] 
> 设 $f(x)$ 在 $[0,1]$ 上连续，单调减少
> 
> 求证： 
> 
> $$\int_{0}^{a} f(x)\mathrm{d}x \geqslant a\int_{0}^{1} f(x)\mathrm{d}x \quad (0 < a < 1)$$

证明：

**法一**

两个积分的积分区间不同，而 0 < a < 1，右边的积分可以分段，故只要证 

$$\int_{0}^{a} f(x)\mathrm{d}x \geqslant a\int_{0}^{a} f(x)\mathrm{d}x + a\int_{a}^{1} f(x)\mathrm{d}x$$

即 

$$(1-a)\int_{0}^{a} f(x)\mathrm{d}x \geqslant a\int_{a}^{1} f(x)\mathrm{d}x$$

观察到左边 1 - a 正好是右边积分区间的差值，我们想到[[积分中值定理]]，

$$(1-a)\int_{0}^{a} f(x)\mathrm{d}x = a(1-a)f(c_1), \quad 0 < c_1 < a$$

$$a\int_{a}^{1} f(x)\mathrm{d}x = a(1-a)f(c_2), \quad a < c_2 < 1$$

由于 $f(x)$ 单调减少，则 $f(c_1) > f(c_2)$，从而 

$$(1-a)\int_{0}^{a} f(x)\mathrm{d}x \geqslant a\int_{a}^{1} f(x)\mathrm{d}x$$

证毕

**法二**

统一积分区间我们还能用变量代换：

$$\int_{0}^{a} f(x)\mathrm{d}x \xlongequal{\text{令} x = at} a\int_{0}^{1} f(at)\mathrm{d}t = a\int_{0}^{1} f(ax)\mathrm{d}x$$

由于 $f(x)$ 单调减少，而 $ax < x$，则 $f(ax) \geqslant f(x)$，从而有 

$$a\int_{0}^{1} f(ax)\mathrm{d}x \geqslant a\int_{0}^{1} f(x)\mathrm{d}x$$

即 $$\int_{0}^{a} f(x)\mathrm{d}x \geqslant a\int_{0}^{1} f(x)\mathrm{d}x$$

证毕

**法三**

既然题目告诉我们单调性了，我们使用变上限积分，将命题转化为讨论函数值的大小，令 

$$F(a) = \int_{0}^{a} f(x)\mathrm{d}x - a\int_{0}^{1} f(x)\mathrm{d}x, (0 \leqslant a \leqslant 1)$$

求导：

$$F'(a) = f(a) - \int_{0}^{1} f(x)\mathrm{d}x$$

这里我们用[[积分中值定理]]拿掉积分号，

$$
= f(a) - f(c),\quad 0 < c < 1
$$

由于 $f(x)$ 单调减少，则当 $0 < a < c$ 时，$F'(a) > 0$，$F(a)$ 单调增加；

当 $c < a < 1$ 时，$F'(a) < 0$，$F(a)$ 单调减少

则 $F(a)$ 在 $[0,1]$ 上的最小值必在区间的端点取到

又 $F(0) = F(1) = 0$，则 $F(a) \geqslant 0$

原题得证
