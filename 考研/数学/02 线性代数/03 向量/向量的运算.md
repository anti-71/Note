向量是特殊的矩阵，故其运算规则与矩阵一致

设 $n$ 维向量 $\boldsymbol{\alpha} = (a_1,a_2,\dots,a_n)^T$，$\boldsymbol{\beta} = (b_1,b_2,\dots,b_n)^T$，则：

##### 1）向量加法

$$
\boldsymbol{\alpha} + \boldsymbol{\beta} = (a_1+b_1, a_2+b_2, \dots, a_n+b_n)^T
$$

##### 2）数乘向量

$$
k\boldsymbol{\alpha} = (ka_1, ka_2, \dots, ka_n)^T
$$

##### 3）向量内积

$$
(\boldsymbol{\alpha}, \boldsymbol{\beta}) = \boldsymbol{\alpha}^T \boldsymbol{\beta} = \boldsymbol{\beta}^T \boldsymbol{\alpha} = a_1b_1 + a_2b_2 + \dots + a_nb_n
$$

> [!note]
> 1. 向量 $\boldsymbol{\alpha} = (a_1,a_2,\dots,a_n)^T$ 的长度（模）为   
>    $$
>    \|\boldsymbol{\alpha}\| = \sqrt{\boldsymbol{\alpha}^T \boldsymbol{\alpha}} = \sqrt{a_1^2 + a_2^2 + \dots + a_n^2}
>    $$
>
> 2. $\boldsymbol{\alpha}^T \boldsymbol{\alpha} = 0 \iff a_1^2 + a_2^2 + \dots + a_n^2 = 0 \iff \boldsymbol{\alpha} = \boldsymbol{0}$
> 3. 内积满足 **对称性**：$(\boldsymbol{\alpha}, \boldsymbol{\beta}) = (\boldsymbol{\beta}, \boldsymbol{\alpha})$； 
>
>    同时内积具有 **线性性**：$$(k\boldsymbol{\alpha}, \boldsymbol{\beta}) = k(\boldsymbol{\alpha}, \boldsymbol{\beta})$$$$(\boldsymbol{\alpha}_1 + \boldsymbol{\alpha}_2, \boldsymbol{\beta}) = (\boldsymbol{\alpha}_1, \boldsymbol{\beta}) + (\boldsymbol{\alpha}_2, \boldsymbol{\beta})$$
>
> 4. 若 $(\boldsymbol{\alpha}, \boldsymbol{\beta}) = 0$（即 $a_1b_1 + a_2b_2 + \dots + a_nb_n = 0$），称 $\boldsymbol{\alpha}$ 与 $\boldsymbol{\beta}$ **正交**，记为 $\boldsymbol{\alpha} \perp \boldsymbol{\beta}$
