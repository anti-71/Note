对于方程组(Ⅰ)和(Ⅱ)，如果 $\boldsymbol{\alpha}$ 既是方程组(Ⅰ)的解，也是方程组(Ⅱ)的解，则称 $\boldsymbol{\alpha}$ 是方程(Ⅰ)和(Ⅱ)的 **公共解**

人们对方程组的公共解有三种不同的理解，进而衍生出三种不同的求公共解的方法

##### 1）联立而成的新方程组的解

##### 2）其中一个方程组的通解中满足另外一个方程组的部分 

若给出 $A_{m \times n}\boldsymbol{x} = \boldsymbol{0}$ 的基础解系 $\boldsymbol{\xi}_1,\boldsymbol{\xi}_2,\dots,\boldsymbol{\xi}_s$

可将 $A_{m \times n}\boldsymbol{x} = \boldsymbol{0}$ 的通解 $k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_s\boldsymbol{\xi}_s$ 代入 $B_{p \times n}\boldsymbol{x} = \boldsymbol{0}$，求出 $k_i(i=1,2,\dots,s)$ 之间的关系

代回 $A_{m \times n}\boldsymbol{x} = \boldsymbol{0}$ 的通解，即得公共解

##### 3）能够同时写成两个方程组通解形式的向量 

若给出 $A_{m \times n}\boldsymbol{x} = \boldsymbol{0}$ 的基础解系 $\boldsymbol{\xi}_1,\boldsymbol{\xi}_2,\dots,\boldsymbol{\xi}_s$ 与 $B_{m \times n}\boldsymbol{x} = \boldsymbol{0}$ 的基础解系 $\boldsymbol{\eta}_1,\boldsymbol{\eta}_2,\dots,\boldsymbol{\eta}_t$，则公共解 $\boldsymbol{\gamma} = k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_s\boldsymbol{\xi}_s = l_1\boldsymbol{\eta}_1 + l_2\boldsymbol{\eta}_2 + \dots + l_t\boldsymbol{\eta}_t$，即

$$
 k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_s\boldsymbol{\xi}_s - l_1\boldsymbol{\eta}_1 - l_2\boldsymbol{\eta}_2 - \dots - l_t\boldsymbol{\eta}_t = \boldsymbol{0}
$$

解此式，求出 $k_i$ 或 $l_j$，$i=1,2,\dots,s$；$j=1,2,\dots,t$，即可求出 $\boldsymbol{\gamma}$
