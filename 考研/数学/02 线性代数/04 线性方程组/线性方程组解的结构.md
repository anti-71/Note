##### 基础解系定义

对于齐次线性方程组 $A\boldsymbol{x} = \boldsymbol{0}$，若向量组 $\boldsymbol{\xi}_1, \boldsymbol{\xi}_2, \dots, \boldsymbol{\xi}_s$ 满足：

1. $\boldsymbol{\xi}_1, \boldsymbol{\xi}_2, \dots, \boldsymbol{\xi}_s$ 均为 $A\boldsymbol{x} = \boldsymbol{0}$ 的解；
2. $\boldsymbol{\xi}_1, \boldsymbol{\xi}_2, \dots, \boldsymbol{\xi}_s$ 线性无关；
3. $A\boldsymbol{x} = \boldsymbol{0}$ 的任一解均能由 $\boldsymbol{\xi}_1, \boldsymbol{\xi}_2, \dots, \boldsymbol{\xi}_s$ 线性表示

则称 $\boldsymbol{\xi}_1, \boldsymbol{\xi}_2, \dots, \boldsymbol{\xi}_s$ 是 $A\boldsymbol{x} = \boldsymbol{0}$ 的一个 **基础解系**

对任意常数 $k_1, k_2, \dots, k_s$，$k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_s\boldsymbol{\xi}_s$ 是 $A\boldsymbol{x} = \boldsymbol{0}$ 的 **通解（所有解）**，即 $A\boldsymbol{x} = \boldsymbol{0}$ 的 **解空间**

> [!note]
> 1. 基础解系是解空间的一个极大线性无关组
> 2. 基础解系是不唯一的，满足：
> 	1. 均为 $A_{m\times n}\boldsymbol{x}=\boldsymbol{0}$ 的解；
> 	2. 线性无关；
> 	3. 个数为 $n-R(A)$ 的向量组
> 	
> 	均可作为 $A_{m\times n}\boldsymbol{x}=\boldsymbol{0}$ 的一个基础解系
> 3. 与齐次方程组 $A_{m \times n}\boldsymbol{x} = \boldsymbol{0}$ 基础解系 **等价的无关向量组**，也为该方程组的一个基础解系

##### 齐次与非齐次方程组解的关系

设方程组：(Ⅰ) $A_{m \times n}\boldsymbol{x} = \boldsymbol{0}$，(Ⅱ) $A_{m \times n}\boldsymbol{x} = \boldsymbol{\beta}$，则有以下结论：

1. 若 $\boldsymbol{\xi}_1$ 与 $\boldsymbol{\xi}_2$ 为 (Ⅰ) 的解，则 $k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2$ 为 (Ⅰ) 的解（$k_1, k_2$ 为任意常数）；
2. 若 $\boldsymbol{\eta}_1$ 与 $\boldsymbol{\eta}_2$ 为 (Ⅱ) 的解，则 $\boldsymbol{\eta}_1 - \boldsymbol{\eta}_2$ 为 (Ⅰ) 的解；
3. (Ⅱ) 的通解 = (Ⅰ) 的通解 + (Ⅱ) 的特解，即：
   
   若齐次方程组的通解为 $k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_s\boldsymbol{\xi}_s$，$\boldsymbol{\eta}$ 为非齐次方程组的一个特解，则非齐次方程组的通解为 $\boldsymbol{x} = k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_s\boldsymbol{\xi}_s + \boldsymbol{\eta}$；

4. (Ⅰ) 的基础解系中含向量的个数为 $n - R(A)$（无须证明）即：
   
   齐次方程组基础解系的向量个数 $s = n - R(A)$
   
   其通解常表示为 $\boldsymbol{x} = k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_{n-R(A)}\boldsymbol{\xi}_{n-R(A)}$；非齐次方程组的通解常表示为 $\boldsymbol{x} = k_1\boldsymbol{\xi}_1 + k_2\boldsymbol{\xi}_2 + \dots + k_{n-R(A)}\boldsymbol{\xi}_{n-R(A)} + \boldsymbol{\eta}$

齐次方程组基础解系的向量个数为 $n - R(A)$，也称齐次线性方程组解空间的秩为 $n - R(A)$

> [!note] 
> 上述结论的核心是 “代入”（除了结论 4）
