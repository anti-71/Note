> [!question]
>
> $\displaystyle\int x\mathrm{e}^x\cos x \,\mathrm{d}x$

由 $\mathrm{d}\big[\mathrm{e}^x(\cos x + \sin x)\big] = 2\mathrm{e}^x\cos x\,\mathrm{d}x$ 得

$$
\begin{aligned}
\text{原式} &= \frac12 \int x \,\mathrm{d}\big[\mathrm{e}^x(\cos x + \sin x)\big] \\
&= \frac12 x\mathrm{e}^x(\cos x + \sin x) - \frac12\int \mathrm{e}^x(\cos x + \sin x)\,\mathrm{d}x \\
&= \frac12 x\mathrm{e}^x(\cos x + \sin x) - \frac14\mathrm{e}^x(\cos x + \sin x) - \frac14\mathrm{e}^x(-\cos x + \sin x) + C \\
&= \frac12 x\mathrm{e}^x(\cos x + \sin x) - \frac12\mathrm{e}^x\sin x + C
\end{aligned}
$$
