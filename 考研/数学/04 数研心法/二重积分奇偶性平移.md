# 二重积分奇偶性平移

回忆：

[[利用对称性和奇偶性计算|普通的二重积分的奇偶性]]，积分域关于 x 轴或 y 轴对称，此时，若被积函数关于 y 轴（即 x = 0）或 x 轴（即 y = 0）具有奇偶性，则可相应简化积分

推广：

那么，若积分域关于 x = a 对称（y = a 同理），想到若被积函数关于 x - a = 0 具有奇偶性，那么，也可以相应简化积分

由此，若题目的积分域关于某条直线对称，我们可以凑出 x - a 的奇偶形式，从而简化计算
