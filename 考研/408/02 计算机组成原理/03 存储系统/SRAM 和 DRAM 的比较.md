下表详细列出了 SRAM 和 DRAM 各自的特点

| 特点    | 类型 - SRAM | 类型 - DRAM |
| ----- | --------- | --------- |
| 存储信息  | 触发器       | 电容        |
| 破坏性读出 | 非         | 是         |
| 需要刷新  | 不需要       | 需要        |
| 送行列地址 | 同时送       | 分两次送（复用）  |
| 运行速度  | 快         | 慢         |
| 集成度   | 低         | 高         |
| 存储成本  | 高         | 低         |
| 主要用途  | 高速缓存      | 主机内存      |
