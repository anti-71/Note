##### 进程调度方式的定义

所谓 **进程调度方式**，是指：

当某个进程正在 CPU 上执行时，若有某个更为重要或紧迫的进程需要处理，即有优先级更高的进程进入就绪队列，此时系统应如何分配 CPU

通常有以下两种进程调度方式

##### 1）非抢占调度方式

###### 基本概念

也称 **非剥夺方式**

指当一个进程正在 CPU 上执行时，即使有某个更为重要或紧迫的进程进入就绪队列，系统仍让当前进程继续执行，直到该进程运行完成（例如正常结束或异常终止），或者因发生某种事件（如等待 I/O 操作、在进程通信或同步中执行了 Block 原语）而主动进入阻塞态，此时才会将 CPU 分配给其他进程

###### 优点

实现简单、系统开销小，适用于早期的批处理系统；

###### 缺点

无法满足分时系统和大多数实时系统对及时响应的要求

##### 2）抢占调度方式

###### 基本概念

也称 **剥夺方式**

指当一个进程正在 CPU 上执行时，若出现更高优先级的就绪进程，调度程序可依据一定策略 **暂停当前进程**，将 CPU 分配给更紧迫的进程

###### 特点

提高系统吞吐量和响应效率

###### 抢占遵循原则

- 优先级
- 短进程优先
- 时间片原则
