##### 整型信号量定义

**整型信号量** 用一个整型变量 S 表示某类资源的可用数量

与普通整型变量不同，对其操作仅限于三种：

- 初始化
- wait 操作
- signal 操作

##### 行为描述

```c
wait(S) {                //相当于进入区（原子操作）
    while(S<=0);         //若资源数不够，则一直循环等待
    S=S-1;               //若资源数够，则占用一个资源
}
signal(S) {             //相当于退出区（原子操作）
    S=S+1;               //使用完后，就释放一个资源
}
```

##### 缺点

在整型信号量机制中，当 $S\leqslant0$ 时，进程将持续循环测试，处于 **忙等待** 状态

这种实现 **未遵循 “让权等待” 准则**，会浪费 CPU 时间，尤其是在单 CPU 系统中效率低下
