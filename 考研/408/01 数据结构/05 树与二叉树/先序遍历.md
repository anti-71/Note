若二叉树为空，则不执行任何操作；否则，

1. 访问根结点；
2. 先序遍历左子树；
3. 先序遍历右子树

对应的递归算法如下：

```c
void PreOrder(BiTree T) {
    if(T!=NULL) {
        visit(T);                //访问根结点
        PreOrder(T->lchild);     //递归遍历左子树
        PreOrder(T->rchild);     //递归遍历右子树
    }
}
```
