若二叉树为空，则不执行任何操作；否则，

1. 中序遍历左子树；
2. 访问根结点；
3. 中序遍历右子树

对应的递归算法如下：

```c
void InOrder(BiTree T) {
    if(T!=NULL) {
        InOrder(T->lchild);      //递归遍历左子树
        visit(T);                //访问根结点
        InOrder(T->rchild);      //递归遍历右子树
    }
}
```
