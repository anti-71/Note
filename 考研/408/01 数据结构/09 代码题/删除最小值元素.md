##### 问题描述

> [!question] 
> 从顺序表中删除具有最小值的元素（假设唯一），并由函数返回被删元素的值，空出的位置由最后一个元素填补，若顺序表为空，则显示出错信息并退出运行

##### 算法思想

1.  遍历顺序表，找到最小值元素及其位置
2.  用最后一个元素覆盖最小值元素的位置（填补空位）
3.  表长减 1
4.  通过引用参数返回最小值

##### 代码实现

```cpp
bool Del_Min(SqList &L, ElemType &min) {
    if (L.length == 0) 
        return false;
    min = L.elem[0];
    int pos;
    for (int i = 1; i < L.length; i++) {
        if (min > L.elem[i]) {
            min = L.elem[i];
            pos = i;
        }
    }
    L.elem[pos] = L.elem[L.length - 1];
    L.length--;
    return true;
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$
- **空间复杂度：** $O(1)$

##### 参考答案

```cpp
bool Del_Min(SqList &L, ElemType &value) {
    // 删除顺序表 L 中最小值元素结点，并通过引用型参数 value 返回其值
    // 若删除成功，则返回 true；否则返回 false
    if (L.length == 0)
        return false;                 // 表空，中止操作返回
    value = L.data[0];
    int pos = 0;                      // 假定 0 号元素的值最小
    for (int i = 1; i < L.length; i++) // 循环，寻找具有最小值的元素
        if (L.data[i] < value) {      // 让 value 记忆当前具有最小值的元素
            value = L.data[i];
            pos = i;
        }
    L.data[pos] = L.data[L.length - 1]; // 空出的位置由最后一个元素填补
    L.length--;
    return true;                      // 此时，value 为最小值
}
```

##### 评分分析

**评分：7 / 10**

| 方面 | 得分 | 说明 |
|------|:----:|------|
| 核心逻辑正确 | ✅ 满分 | 遍历找最小 → 最后一个元素填补 → 表长减 1，思路完整 |
| 边界处理 | ✅ 满分 | 空表判断 `L.length == 0` 返回 false |
| 参数返回 | ✅ 满分 | 使用引用参数 `&min` 返回最小值 |
| 变量初始化 | ❌ 扣 3 分 | `int pos` 未初始化，最小值在 `L.elem[0]` 时 `pos` 未定义，导致数组越界 |

**扣分说明：** 参考答案使用 `int pos = 0` 解决了此问题

##### 修改建议

1.  **初始化 `pos = 0`** — 假定 0 号元素最小，避免最小值在首位时 `pos` 未定义
2.  参数名 `min` 语义偏向 "最小值"，改用 `value` 更通用，与主流参考书习惯一致
3.  可适当添加关键注释（如 `int pos = 0` 和 `L.data[pos] = ...` 处），便于阅卷快速理解意图
