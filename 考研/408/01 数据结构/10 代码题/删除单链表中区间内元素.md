##### 问题描述

> [!question] 
> 设在一个带表头结点的单链表中，所有结点的元素值无序，试编写一个函数，删除表中所有处于给定的两个值（作为函数参数给出）之间的元素（若存在）

##### 算法思想

由于链表无序，无法利用有序性优化，只能逐个检查每个结点。用指针 p 从头结点开始遍历，每次检查 p->next 是否处于给定区间内：若是，则删除并 free，p 保持不动；否则 p 后移

##### 代码实现

```cpp
void Delete_Range(LinkList &L, ElemType a, ElemType b) {
    LNode *p = L.head;
    while (p->next != NULL) {
        if (p->next->data >= a && p->next->data <= b) {
            LNode *q = p->next;
            p->next = q->next;
            free(q);
        }
        else
            p = p->next;
    }
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 只需一次扫描
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
void RangeDelete(LinkList &L, int min, int max) {
    LNode *pr = L, *p = L->link;        // p 为检测指针，pr 为其前驱
    while (p != NULL)
        if (p->data > min && p->data < max) { // 找到被删结点
            pr->link = p->link;
            free(p);
            p = pr->link;
        } else {                              // 否则继续寻找
            pr = p;
            p = p->link;
        }
}
```

##### 补充说明

注意区间边界的判定：参考答案使用严格不等式 `> min && < max`（开区间），你的代码使用 `>= a && <= b`（闭区间）

具体采用哪种取决于题目对"之间"的定义，建议看清题意后调整条件符号
