##### 问题描述

> [!question] 
> 在一个递增有序的单链表中，存在重复的元素，设计算法删除重复的元素。例如 $(7, 10, 10, 21, 30, 42, 42, 42, 51, 70)$ 将变为 $(7, 10, 21, 30, 42, 51, 70)$

##### 算法思想

链表是递增有序的，因此值相同的结点必然相邻

用 p 扫描链表，若当前结点与其后继结点值相等，则删除后继结点并继续检查；否则 p 后移

只需一次遍历

##### 代码实现

```cpp
void Delete_Repeat(LinkList &L) {
    LNode *pre = L.head;
    LNode *p = pre->next;
    while (p != NULL) {
        if (p->data == pre->data) {
            LNode *temp = p;
            pre->next = p->next;
            p = p->next;
            free(temp);
        }
        else {
            p = p->next;
            pre = pre->next;
        }
    }
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 只需一次扫描
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
void Del_Same(LinkList &L) {
    LNode *p = L->next, *q;           // p 为扫描工作指针
    if (p == NULL)
        return;
    while (p->next != NULL) {
        q = p->next;                  // q 指向*p 的后继结点
        if (p->data == q->data) {     // 找到重复值的结点
            p->next = q->next;
            free(q);                  // 释放相同元素值的结点
        }
        else
            p = p->next;
    }
}
```

##### 补充说明

注意你的代码中 `pre` 的初始值为 `L.head`（头结点）

第一轮循环会比较 `p->data == pre->data`，即首结点的值与头结点的值比较。若头结点数据域未初始化（或恰好与首结点值相同），可能导致首结点被误删

参考答案从第一个数据结点开始比较 `p->data` 与 `p->next->data`，避免了这一问题

| 删除逻辑 | ✅ 满分 | 重复结点相邻的性质利用正确，删除并释放空间 |
| 边界处理 | ✅ 满分 | 空链表时 `p = NULL`，`while` 循环不进入，自然安全；连续多个重复值也能正确删除 |
| 复杂度 | ✅ 满分 | $O(n)$ 时间，$O(1)$ 空间 |

##### 修改建议

1. **修正首轮比较**：让 `pre` 直接指向第一个数据结点（`L.head->next`），或改用参考答案的写法（`p` 与 `p->next` 比较），避免与头结点的空数据域比较
