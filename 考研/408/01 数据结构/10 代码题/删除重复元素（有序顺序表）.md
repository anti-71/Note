##### 问题描述

> [!question] 
> 从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不同

##### 算法思想

因为是有序顺序表，值相同的元素一定在连续的位置上，所以用类似于直接插入排序的思路：初始时将第一个元素视为非重复的有序表，之后依次判断后面的元素是否与前面非重复有序表的最后一个元素相同；若相同，则继续向后判断；若不同，则插入前面的非重复有序表的最后，直至判断到表尾为止

##### 参考答案

```cpp
bool Delete_Same(SeqList& L){
    if(L.length == 0)
        return false;
    int i, j;                     // i 存储第一个不相同的元素，j 为工作指针
    for(i = 0, j = 1; j < L.length; j++)
        if(L.data[i] != L.data[j]) // 查找下一个与上一个元素值不同的元素
            L.data[++i] = L.data[j]; // 找到后，将元素前移
    L.length = i + 1;
    return true;
}
```

##### 补充说明

本题的关键在于利用有序顺序表的特性 —— 重复元素必然相邻，因此只需一次扫描即可完成去重，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$

若顺序表无序，则需要先排序或借助辅助空间（如哈希表）来处理
