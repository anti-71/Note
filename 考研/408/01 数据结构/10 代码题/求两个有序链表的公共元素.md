##### 问题描述

> [!question] 
> 设 A 和 B 是两个单链表（带头结点），其中元素递增有序，设计一个算法从 A 和 B 中的公共元素产生单链表 C，要求不破坏 A、B 的结点

##### 算法思想

A、B 均递增有序，可从第一个元素起依次比较两表元素：若值不等，则值小的指针后移；若值相等，则创建一个值相等的新结点，用尾插法插入 C，并将两个原表指针同时后移

重复直至某个链表遍历到表尾

##### 代码实现

```cpp
void GenerateC(LinkList &A, LinkList &B, LinkList &C) {
    LNode *p1 = A.head->next, *p2 = B.head->next, *p3 = C.head;
    while (p1 != NULL && p2 != NULL) {
        if (p1->data == p2->data) {
            ElemType x = p1->data;
            LNode *temp = (LNode *)malloc(sizeof(LNode));
            temp->data = x;
            temp->next = NULL;
            p3->next = temp;
            p1 = p1->next;
            p2 = p2->next;
            p3 = p3->next;
        }
        else if (p1->data < p2->data)
            p1 = p1->next;
        else
            p2 = p2->next;
    }
}
```

##### 复杂度分析

- **时间复杂度：** $O(m + n)$ — 两表各扫描一遍
- **空间复杂度：** $O(k)$ — 需要为新链表 C 申请 $k$ 个结点（$k$ 为公共元素个数），这是输出所需空间，辅助空间为 $O(1)$

##### 参考答案

```cpp
void Get_Common(LinkList A, LinkList B) {
    LNode *p = A->next, *q = B->next, *r, *s;
    LinkList C = (LinkList)malloc(sizeof(LNode));  // 建立表 C
    r = C;                                         // r 始终指向 C 的尾结点
    while (p != NULL && q != NULL) {               // 循环跳出条件
        if (p->data < q->data)
            p = p->next;                           // A 的当前元素较小，后移指针
        else if (p->data > q->data)
            q = q->next;                           // B 的当前元素较小，后移指针
        else {                                     // 找到公共元素结点
            s = (LNode *)malloc(sizeof(LNode));
            s->data = p->data;                     // 复制产生结点*s
            r->next = s;                           // 将*s 链接到 C 上（尾插法）
            r = s;
            p = p->next;                           // 表 A 和 B 继续向后扫描
            q = q->next;
        }
    }
    r->next = NULL;                                // 置 C 尾结点指针为空
}
```

##### 补充说明

你的代码正确实现了归并比较，且新结点在创建时即设置 `temp->next = NULL`，因此 C 表尾天然正确终止。与参考答案的差异仅在于 C 的创建方式（你作为参数传入，参考答案在函数内 malloc 并返回），两者均符合"不破坏 A、B"的要求
