##### 问题描述

> [!question] 
> 两个整数序列 $A = a_1, a_2, \dots, a_m$ 和 $B = b_1, b_2, \dots, b_n$ 已经存入两个单链表中，设计一个算法，判断序列 B 是否是序列 A 的连续子序列

##### 算法思想

从 A、B 的第一个结点开始比较：若对应数据相等，则两指针同时后移；若不等，则 A 从上次比较开始结点的后继重新比较，B 仍从第一个结点开始

直到 B 到尾表示匹配成功；A 到尾而 B 未到尾表示失败

需记住 A 每次比较的开始结点

##### 代码实现

```cpp
bool Is_SubList(LinkList &A, LinkList &B, int m, int n) {
    bool flag = false;
    int i, j;
    LNode *p = A.head->next;
    for (i = 0; i < m; i++) {
        LNode *q = B.head->next, *pp = p;   // 每趟比较开始时初始化一次
        for (j = 0; j < n; j++) {
            if (pp->data != q->data)
                break;
            if (j == n - 1) {
                flag = true;
                break;
            }
            pp = pp->next;
            q = q->next;
        }
        if (flag)
            break;
        p = p->next;
    }
    return flag;
}
```

##### 复杂度分析

- **时间复杂度：** $O(m \times n)$ — 最坏情况每趟比较都要回溯
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
int Pattern(LinkList A, LinkList B) {
    LNode *p = A;             // p 为 A 链表的工作指针（假定 A、B 均无头结点）
    LNode *pre = p;           // pre 记住每趟比较中 A 链表的开始结点
    LNode *q = B;             // q 是 B 链表的工作指针
    while (p && q)
        if (p->data == q->data) { // 结点值相同
            p = p->next;
            q = q->next;
        }
        else {
            pre = pre->next;
            p = pre;          // A 链表新的开始比较结点
            q = B;            // q 从 B 链表第一个结点开始
        }
    if (q == NULL)            // B 已经比较结束
        return 1;             // B 是 A 的子序列
    else
        return 0;             // B 不是 A 的子序列
}
```

##### 补充说明

本题实为字符串模式匹配的链式表示。新作答已修复核心 bug：`q`、`pp` 移到外层循环声明，每趟比较开始时初始化一次，内层循环中能真正同步后移逐位比较，常规情况匹配正确

但还存在一个边界 bug：外层循环条件 `i < m` 未保证 A 剩余结点数 ≥ n，当 B 比 A 剩余部分长时，`pp` 会越过 A 尾部变成 NULL，下一轮 `pp->data` 解引用空指针崩溃（如 A={1,2,3,4}、B={3,4,5}）

应将外层循环改为 `i <= m - n` 或在循环内加 `pp == NULL` 判断

##### 修改建议

1. **修正边界崩溃**：将外层循环条件 `i < m` 改为 `i <= m - n`，保证 A 剩余结点数 ≥ n，否则 B 不可能成为 A 的连续子序列：

```cpp
for (i = 0; i <= m - n; i++) {
```

2. **回溯逻辑**：参考答案用 `pre` 记住 A 的每趟起点 + `while (p && q)` 判断，天然避免空指针问题，写法更简洁，无需传 `m`、`n` 参数
