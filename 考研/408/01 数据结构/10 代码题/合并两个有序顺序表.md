##### 问题描述

> [!question] 
> 将两个有序顺序表合并为一个新的有序顺序表，并由函数返回结果顺序表

##### 算法思想

首先，按顺序不断取下两个顺序表表头较小的结点存入新的顺序表中；然后，看哪个表还有剩余，将剩下的部分全部加到新的顺序表后面

##### 代码实现

```cpp
SqList Merge(SqList L1, SqList L2) {
    SqList L;
    int i, j = 0, s = 1;
    InitList(&L);
    for (i = 0; i < L1.length; i++) {
        while (L2.elem[j] <= L1.elem[i] && j < L2.length) {
            ListInsert(&L, s, L2.elem[j]);
            s++;
            j++;
        }
        ListInsert(&L, s, L1.elem[i]);
        s++;
    }
    if (i != L1.length - 1) {
        for (; i < L1.length; i++) {
            ListInsert(&L, s, L1.elem[i]);
            s++;
        }
    }
    if (j != L2.length - 1) {
        for (; j < L2.length; j++) {
            ListInsert(&L, s, L2.elem[j]);
            s++;
        }
    }
    return L;
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 虽然代码中有两层循环（`for` 嵌套 `while`），但内层 `while` 的指针 `j` 只向前移动、从不重置，每个元素在整个过程中最多被处理一次，总操作数仍为线性
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
bool Merge(SeqList A, SeqList B, SeqList &C) {
    // 将有序顺序表 A 与 B 合并为一个新的有序顺序表 C
    if (A.length + B.length > C.maxSize)  // 大于顺序表的最大长度
        return false;
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) { // 循环，两两比较，小者存入结果表
        if (A.data[i] <= B.data[j])
            C.data[k++] = A.data[i++];
        else
            C.data[k++] = B.data[j++];
    }
    while (i < A.length)                   // 还剩一个没有比较完的顺序表
        C.data[k++] = A.data[i++];
    while (j < B.length)
        C.data[k++] = B.data[j++];
    C.length = k;
    return true;
}
```

##### 补充说明

合并操作类似于归并排序中的归并过程，利用了有序表的优势

##### 评分分析

**评分：8 / 10**

| 方面 | 得分 | 说明 |
|------|:----:|------|
| 核心思路 | ✅ 满分 | 双指针归并，小者先入，思路正确 |
| 边界处理 | ❌ 扣 2 分 | 剩余 L2 元素判断 `j != L2.length - 1` 在恰剩一个元素时漏插 |

**扣分说明：** 剩余元素的处理意图正确（判断 L2 是否还有元素未加入），但条件写成了 `j != L2.length - 1`，当 `j == L2.length - 1`（恰剩一个元素）时条件为 false，导致该元素丢失

应改用 `while (j < L2.length)`，或 `if (j < L2.length)` 后接循环

##### 修改建议

1. **修复剩余元素处理 bug**：将 `if (j != L2.length - 1)` 改为 `while (j < L2.length)`，与 L1 的剩余处理逻辑统一
2. **去除冗余代码**（非必须）：for 循环结束后 `i` 已为 `L1.length`，`if (i != L1.length - 1)` 恒为 true，但内层 `for(; i < L1.length; i++)` 因 `i` 已越界而永不执行，属于无害的死代码，可删除
