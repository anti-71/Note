##### 问题描述

> [!question] 
> 设计一个算法用于判断带头结点的循环双链表是否对称

##### 算法思想

先遍历一遍统计结点个数，然后让 p 从左向右、q 从右向左相向扫描，比较前一半结点与后一半对应结点是否相等，若有不等则不对称，全部相等则对称

##### 代码实现

```cpp
bool Is_Sym(CDLinkList &L) {
    bool flag = true;
    int l = 0, i;
    DNode *p = L.head->next, *q = L.head;
    while (q->next != L.head) {   // 统计结点个数
        l++;
        q = q->next;
    }
    for (i = 0; i < l / 2; i++) { // 只比较一半
        if (p->data != q->data) {
            flag = false;
            break;
        }
        p = p->next;
        q = q->prev;
    }
    return flag;
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 先遍历求长度一趟，再比较 $\dfrac n2$ 次，合计约 1.5 趟
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
int Symmetry(DLinkList L) {
    DNode *p = L->next, *q = L->prior;   // 两头工作指针
    while (p != q && p->next != q)       // 循环跳出条件
        if (p->data == q->data) {        // 所指结点值相同则继续比较
            p = p->next;
            q = q->prior;
        }
        else                             // 否则，返回 0
            return 0;
    return 1;                            // 比较结束后返回 1
}
```

##### 补充说明

参考答案无需先求长度，直接用双指针相向移动，以 `p == q`（奇数个结点）或 `p->next == q`（偶数个结点）作为相遇判断，单趟完成比较。注意循环条件不能误写成 `q->next != p`，否则偶数个结点时会漏判

##### 修改建议

可去掉求长度的遍历，改用参考答案的双指针相遇判断：

```cpp
bool Is_Sym(CDLinkList &L) {
    DNode *p = L.head->next, *q = L.head->prev;  // 两端工作指针
    while (p != q && p->next != q)
        if (p->data != q->data)
            return false;
        else {
            p = p->next;
            q = q->prev;
        }
    return true;
}
```
