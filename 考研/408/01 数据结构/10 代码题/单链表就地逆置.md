##### 问题描述

> [!question] 
> 试编写算法将带头结点的单链表就地逆置，所谓"就地"是指辅助空间复杂度为 $O(1)$

##### 算法思想

解法一（头插法）：将头结点摘下，然后从第一结点开始，依次用头插法插入到头结点之后，直至最后一个结点为止

解法二（指针反转）：用三个相邻指针 pre、p、r 遍历链表，依次将每个结点的 next 指向其原前驱结点，实现指针反转。处理完最后一个结点后，将头结点指向它

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 只需一次扫描
- **空间复杂度：** $O(1)$ — 就地逆置，无额外空间

##### 参考答案

解法一（头插法）：

```cpp
LinkList Reverse_1(LinkList L) {
    LNode *p, *r;                  // p 为工作指针，r 为 p 的后继，以防断链
    p = L->next;                   // 从第一个元素结点开始
    L->next = NULL;                // 先将头结点 L 的 next 域置为 NULL
    while (p != NULL) {            // 依次将元素结点摘下
        r = p->next;               // 暂存 p 的后继
        p->next = L->next;         // 将 p 结点插入到头结点之后
        L->next = p;
        p = r;
    }
    return L;
}
```

解法二（指针反转）：

```cpp
LinkList Reverse_2(LinkList L) {
    LNode *pre, *p = L->next, *r = p->next;
    p->next = NULL;                // 处理第一个结点（将作为新表的尾结点）
    while (r != NULL) {            // r 为空则说明 p 为最后一个结点
        pre = p;                   // 依次继续遍历
        p = r;
        r = r->next;
        p->next = pre;             // 指针反转
    }
    L->next = p;                   // 处理最后一个结点
    return L;
}
```

##### 补充说明

本题两种解法均要求 $O(1)$ 辅助空间，头插法更易理解，指针反转法重在理解三个指针如何配合断链与重接。注意第一个结点逆置后将成为新表的尾结点，其 next 需置为 NULL
