##### 问题描述

> [!question] 
> 设将 $n（n>1）$ 个整数存放到不带头结点的单链表 L 中，设计算法将 L 中保存的序列循环右移 $k（0<k<n）$ 个位置
> 
> 例如，若 $k=1$，则将链表 $\{0,1,2,3\}$ 变为 $\{3,0,1,2\}$
> 
> 要求：
> 1. 给出算法的基本设计思想
> 2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释
> 3. 说明你所设计算法的时间复杂度和空间复杂度

##### 算法思想

遍历链表找到要断开的结点（新链表的尾结点，即原链表的第 $n - k$ 个结点），其后一个结点为新链表的首结点并记录；再遍历到旧链表的尾结点，将尾结点接到旧首结点上形成环，最后令 L 指向记录的新首结点

##### 代码实现

```cpp
void RightMove(LinkList &L, int n, int k) {
    LNode *q = L;
    for (int i = 0; i < n - k - 1; i++)   // q 走到第 n-k 个结点（新链表尾结点）
        q = q->next;
    LNode *p = q->next;                   // p 为新链表首结点
    q->next = NULL;                       // 断开
    q = p;
    while (p->next != NULL)               // p 走到旧链表尾结点
        p = p->next;
    p->next = L;                          // 尾结点接到旧首结点，成环
    L = q;                                // L 指向新首结点
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 只需两趟遍历
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
LNode *Converse(LNode *L, int k) {
    int n = 1;                    // n 用来保存链表的长度
    LNode *p = L;                 // p 为工作指针
    while (p->next != NULL) {     // 计算链表的长度
        p = p->next;
        n++;
    }                             // 循环执行后，p 指向链表尾结点
    p->next = L;                  // 将链表连成一个环
    for (int i = 1; i <= n - k; i++)  // 寻找链表的第 n-k 个结点
        p = p->next;
    L = p->next;                  // 令 L 指向新链表尾结点的下一个结点
    p->next = NULL;               // 将环断开
    return L;
}
```

##### 补充说明

你的代码功能正确：先定位第 $n - k$ 个结点断开，再把旧尾接到旧首成环，最后移动 L

`q = p` 一行略显冗余（直接用 `p` 保存新首结点即可），但不影响正确性

参考答案先在循环里遍历求表长 n，再连成环走 $n - k$ 步定位断开，两种写法等价
