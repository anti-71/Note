##### 问题描述

> [!question] 
> 设计一个高效算法，将顺序表 L 的所有元素逆置，要求算法的空间复杂度为 $O(1)$

##### 算法思想

1.  扫描顺序表 L 的前半部分元素
2.  将 `L.data[i]` 与后半部分的对应元素 `L.data[L.length-i-1]` 进行交换
3.  循环直至所有对称位置交换完毕

##### 代码实现

```cpp
void Swap(ElemType &a, ElemType &b) {
    ElemType temp;
    temp = a;
    a = b;
    b = temp;
    return;
}

void Reverse(SqList &L) {
    int mid = L.length / 2;
    if (L.length % 2 != 0)
        mid++;
    for (; mid < L.length; mid++)
        Swap(L.elem[mid],L.elem[L.length - 1 - mid]);
    return;
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$
- **空间复杂度：** $O(1)$

##### 参考答案

```cpp
void Reverse(SqList &L) {
    ElemType temp;                     // 辅助变量
    for (int i = 0; i < L.length / 2; i++) {
        temp = L.data[i];             // 交换 L.data[i] 与 L.data[L.length-i-1]
        L.data[i] = L.data[L.length - i - 1];
        L.data[L.length - i - 1] = temp;
    }
}
```

##### 评分分析

**评分：8 / 10**

| 方面 | 得分 | 说明 |
|------|:----:|------|
| 核心逻辑正确 | ✅ 满分 | 通过前后对称交换实现逆置，功能正确 |
| 空间复杂度 | ✅ 满分 | 仅使用常数个辅助变量，满足 $O(1)$ 要求 |
| 代码简洁性 | ❌ 扣 2 分 | 循环控制过于复杂，`mid` 计算绕弯，直接用 `for(i=0; i<L.length/2; i++)` 即可 |
| 编码习惯 | ✅ 满分 | 冗余的 `Swap` 函数和末尾 `return;` 不影响正确性 |

**扣分说明：** `mid` 的复杂计算完全可以用 `for (int i = 0; i < L.length / 2; i++)` 替代，参考答案直接循环前半部分下标，更简洁清晰

##### 修改建议

1.  **去掉 `mid` 的复杂计算** — 直接 `for (int i = 0; i < L.length / 2; i++)` 即可完成所有交换
2.  `void` 函数末尾的 `return;` 可省略
3.  交换逻辑简短时可内联实现，不必单独封装 `Swap` 函数
