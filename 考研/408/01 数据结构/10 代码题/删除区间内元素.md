##### 问题描述

> [!question] 
> 从顺序表中删除其值在给定值 $s$ 和 $t$ 之间（包含 $s$ 和 $t$，要求 $s<t$）的所有元素，若 $s$ 或 $t$ 不合理或顺序表为空，则显示出错信息并退出运行

##### 算法思想

从前向后扫描顺序表 $L$，用 $k$ 记录值不在 $s$ 和 $t$ 之间的元素个数（保留的元素个数），将保留的元素依次前移到下标 $k$ 的位置，扫描结束后修改 $L$ 的长度

##### 代码实现

```cpp
bool Delete_Range(SqList &L, ElemType s, ElemType t) {
    if (L.length == 0 || s >= t)
        return false;
    int k = 0;
    for (int i = 0; i < L.length; i++) {
        if (L.elem[i] < s || L.elem[i] > t) {
            L.elem[k] = L.elem[i];
            k++;
        }
    }
    L.length = k;
    return true;  
}
```

##### 参考答案

```cpp
bool Del_s_t(SqList &L, ElemType s, ElemType t) {
    // 删除顺序表 L 中值在给定值 s 和 t（要求 s<t）之间的所有元素
    int i, k = 0;
    if (L.length == 0 || s >= t)
        return false;                 // 线性表为空或 s、t 不合法，返回
    for (i = 0; i < L.length; i++) {
        if (L.data[i] >= s && L.data[i] <= t)
            k++;                     // 记录值在区间内的元素个数
        else
            L.data[i - k] = L.data[i]; // 当前元素前移 k 个位置
    }
    L.length -= k;                   // 长度减小
    return true;
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 仅需一趟扫描
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 补充

本题也可从后向前扫描顺序表，每遇到一个值在 $s$ 和 $t$ 之间的元素就将其删除，并将其后的所有元素全部前移，但移动次数远大于前者，效率不够高
