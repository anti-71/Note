##### 问题描述

> [!question] 
> 给定两个单链表，试分析找出两个链表的公共结点的思想（不用写代码）

##### 算法思想

**你的思路（蛮力法）：** 在第一个链表上顺序遍历每个结点，每遍历一个结点，就在第二个链表上顺序遍历所有结点，比较是否指向同一结点

若找到相同结点，则为第一个公共结点

**更优的思路（长度差 + 双指针）：** 两个单链表从第一个公共结点开始之后的所有结点都是重合的（拓扑形状为 Y 形，而非 X 形）

因此可先分别遍历两个链表得到各自的长度，并求出长度差；然后让较长的链表先向后移动长度差个结点，再让两个指针同步后移，当它们指向同一结点时即为第一个公共结点

##### 复杂度分析

- **蛮力法：** 时间复杂度 $O(\text{len1} \times \text{len2})$，空间复杂度 $O(1)$
- **长度差法：** 时间复杂度 $O(\text{len1} + \text{len2})$，空间复杂度 $O(1)$

##### 参考答案

```cpp
LNode *Search_Common(LinkList L1, LinkList L2) {
    int len1 = Length(L1), len2 = Length(L2);
    LinkList longList = len1 >= len2 ? L1 : L2;
    LinkList shortList = len1 >= len2 ? L2 : L1;
    int dist = abs(len1 - len2);

    while (dist--)
        longList = longList->next;

    while (longList != NULL && shortList != NULL) {
        if (longList == shortList)
            return longList;
        longList = longList->next;
        shortList = shortList->next;
    }
    return NULL;
}
```

##### 补充说明

判断两个链表是否有公共结点，只需遍历到各自的尾结点，若尾结点相同则说明有公共结点（因为公共结点之后的所有结点完全重合）

结合这一性质，长度差 + 双指针同步遍历可在线性时间内找到第一个公共结点

##### 修改建议

可以从两个角度改进分析：

1. 指出单链表结点只有一个 next 域，因此公共结点后必然重合（Y 形拓扑）；
2. 利用尾结点相同即可判定有公共结点的性质，结合长度差法避免嵌套循环
