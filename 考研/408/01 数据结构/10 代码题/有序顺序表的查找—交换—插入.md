##### 问题描述

> [!question] 
> 线性表 $(a_1, a_2, \dots, a_n)$ 中的元素递增有序且按顺序存储于计算机内，要求设计一个算法，完成用最少时间在表中查找数值为 $x$ 的元素，若找到，则将其与后继元素位置相交换；若找不到，则将其插入表中并使表中元素仍然递增有序

##### 算法思想

使用折半查找法在有序顺序表中查找 $x$，时间复杂度为 $O(\log n)$；若找到 $x$ 且其不是最后一个元素，则与后继元素交换；若未找到（$low > high$），则将位置 $high + 1$ 之后的元素全部后移一个位置，然后将 $x$ 插入

##### 代码实现

```cpp
void Find_X(SqList &L, ElemType x) {
    int low = 0, high = L.length - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;
        if (L.elem[mid] == x)
            break;
        else if (L.elem[mid] < x)
            low = mid + 1;
        else
            high = mid - 1;
    }
    if (L.elem[mid] == x && mid != L.length - 1) {
        L.elem[mid] = L.elem[mid + 1];
        L.elem[mid + 1] = x;
    }
    if (low > high) {
        ListInsert(&L, L.length, L.elem[L.length - 1]);
        for (int i = L.length - 2; i > high; i--)
            L.elem[i + 1] = L.elem[i];
        L.elem[high + 1] = x;
    }
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 折半查找 $O(\log n)$，插入时移动元素 $O(n)$，取较大者
- **空间复杂度：** $O(1)$ — 仅使用常数个辅助变量

##### 参考答案

```cpp
void SearchExchangeInsert(ElemType A[], ElemType x) {
    int low = 0, high = n - 1, mid;   // low 和 high 指向顺序表下界和上界
    while (low <= high) {
        mid = (low + high) / 2;       // 找中间位置
        if (A[mid] == x) break;       // 找到 x，退出 while 循环
        else if (A[mid] < x) low = mid + 1;
        else high = mid - 1;
    }
    // 下面两个 if 语句只会执行一个
    if (A[mid] == x && mid != n - 1) { // 若最后一个元素与 x 相等，则不存在与其后继交换的操作
        int t = A[mid];
        A[mid] = A[mid + 1];
        A[mid + 1] = t;
    }
    if (low > high) {                  // 查找失败，插入数据元素 x
        for (int i = n - 1; i > high; i--)
            A[i + 1] = A[i];          // 后移元素
        A[high + 1] = x;              // 插入 x
    }
}
```

##### 补充说明

本题要求"用最少时间查找"，故应使用折半查找而非顺序查找

插入部分的移动操作也可将三个功能拆分为独立函数（查找、交换、插入），逻辑更清晰且易读

**扣分说明：** 你的 `SqList` 是动态扩容的，用 `ListInsert` 来触发 `realloc` 有其合理性。问题在于 `ListInsert` 内部已经做了一次移位（把最后一个元素后移一位），紧接着手动移位又做了一遍，两段位移逻辑割裂。更好的做法是将容量检查独立出来，用一个循环完成全部移位

##### 修改建议

1. **将容量检查与移位分离**（基于你的 `SqList` 实现）：

```cpp
if (low > high) {
    // 确保容量
    if (L.length >= L.capacity) {
        int new_cap = L.capacity + LIST_INCREMENT;
        ElemType *p = (ElemType *)realloc(L.elem, new_cap * sizeof(ElemType));
        if (p == NULL) return;
        L.elem = p;
        L.capacity = new_cap;
    }
    // 从末尾开始统一后移
    for (int i = L.length - 1; i > high; i--)
        L.elem[i + 1] = L.elem[i];
    L.elem[high + 1] = x;
    L.length++;
}
```

2. **交换用临时变量**：`L.elem[mid] = L.elem[mid + 1]; L.elem[mid + 1] = x;` 虽能工作（`x` 已保存），但用 `t = L.elem[mid]; L.elem[mid] = L.elem[mid + 1]; L.elem[mid + 1] = t;` 更标准，阅卷不易误解
