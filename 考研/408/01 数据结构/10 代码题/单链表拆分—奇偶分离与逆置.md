##### 问题描述

> [!question] 
> 设 $C = \{a_1, b_1, a_2, b_2, \dots, a_n, b_n\}$ 为线性表，采用带头结点的单链表存放，设计一个就地算法，将其拆分为两个线性表，使得 $A = \{a_1, a_2, \dots, a_n\}$，$B = \{b_n, \dots, b_2, b_1\}$

##### 算法思想

遍历原链表，将奇数位置结点用尾插法插入 A（保持原序），偶数位置结点用头插法插入 B（实现逆序），一次遍历即可完成拆分

##### 代码实现

```cpp
void List_Split(LinkList &L, LinkList &L1, LinkList &L2) {
    int n = L.length / 2, i;
    LNode *p = L.head->next, *temp, *p1 = L1.head, *p2 = L2.head;
    for (i = 0; i < n; i++) {
        temp = p;
        p = p->next;
        p1->next = temp;
        temp->next = NULL;
        p1 = p1->next;

        temp = p;
        p = p->next;
        if (p2 == L2.head) {          // 第一个偶数结点
            p2->next = temp;
            temp->next = NULL;
            p2 = p2->next;
        } else {                       // 后续偶数结点头插
            L2.head->next = temp;
            temp->next = p2;
            p2 = temp;
        }
    }
}
```

##### 复杂度分析

- **时间复杂度：** $O(n)$ — 只需一次遍历
- **空间复杂度：** $O(1)$ — 就地拆分，未申请新结点

##### 参考答案

```cpp
LinkList DisCreat_2(LinkList &A) {
    LinkList B = (LinkList)malloc(sizeof(LNode)); // 创建 B 表表头
    B->next = NULL;                               // B 表初始化
    LNode *p = A->next, *q;                       // p 为工作指针
    LNode *ra = A;                                // ra 始终指向 A 的尾结点
    while (p != NULL) {
        ra->next = p;                             // 将*p 链到 A 的表尾
        ra = p;
        p = p->next;
        if (p != NULL) {
            q = p->next;                          // 头插后*p 将断链，用 q 记忆后继
            p->next = B->next;                    // 将*p 插入到 B 的前端
            B->next = p;
            p = q;
        }
    }
    ra->next = NULL;                              // A 尾结点的 next 域置空
    return B;
}
```

##### 补充说明

你的代码功能正确，但有以下几点值得注意：

1. 使用 `L.length` 需要 LinkList 结构体包含该字段，若为标准定义 `typedef LNode *LinkList` 则无法直接获取长度；
2. 对 L2 第一个结点和其他结点分别处理使逻辑略显复杂，参考答案统一用头插 + 暂存后继（`q`）的方式更简洁

##### 修改建议

1. **改用 `p != NULL` 终止条件**，无需预先获取链表长度，通用性更强
2. **统一头插写法**：参考参考答案用 `q` 暂存后继再头插，省去首元素的特殊分支判断
3. **返回值设计**：可考虑让函数返回 L2（或 L1），调用方更易使用
