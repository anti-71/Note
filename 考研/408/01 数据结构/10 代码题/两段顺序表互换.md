##### 问题描述

> [!question] 
> 已知在一维数组 $A[m+n]$ 中依次存放两个线性表 $(a_1, a_2, \dots, a_m)$ 和 $(b_1, b_2, \dots, b_n)$，编写一个函数，将数组中两个顺序表的位置互换，即将 $(b_1, b_2, \dots, b_n)$ 放在 $(a_1, a_2, \dots, a_m)$ 的前面

##### 算法思想

先将数组 $A[m+n]$ 中的全部元素原地逆置为 $(b_n, b_{n-1}, \dots, b_1, a_m, a_{m-1}, \dots, a_1)$；然后对前 $n$ 个元素和后 $m$ 个元素分别逆置，即可得到 $(b_1, b_2, \dots, b_n, a_1, a_2, \dots, a_m)$，从而实现顺序表的位置互换

##### 代码实现

```cpp
void Swap(SqList &L, int m, int n) {
    SqList L1, L2;
    InitList(&L1);
    InitList(&L2);
    int i, j;
    for (i = 0; i < m; i++)
        ListInsert(&L1, i + 1, L.elem[i]);
    for (j = 0; j < n; j++)
        ListInsert(&L2, j + 1, L.elem[j + m]);
    for (i = 0; i < n; i++)
        L.elem[i] = L2.elem[i];
    for (j = 0; j < m; j++)
        L.elem[j + n] = L1.elem[j];
}
```

##### 复杂度分析

- **时间复杂度：** $O(m + n)$ — 依次拷贝所有元素
- **空间复杂度：** $O(m + n)$ — 借助了两个辅助顺序表

##### 参考答案

```cpp
typedef int DataType;

void Reverse(DataType A[], int left, int right, int arraySize) {
    // 逆转 A[left..right] 为 A[right..left]
    if (left >= right || right >= arraySize)
        return;
    int mid = (left + right) / 2;
    for (int i = 0; i <= mid - left; i++) {
        DataType temp = A[left + i];
        A[left + i] = A[right - i];
        A[right - i] = temp;
    }
}

void Exchange(DataType A[], int m, int n, int arraySize) {
    // 数组 A[m+n] 中，从 0 到 m-1 存放 (a1,...,am)，从 m 到 m+n-1 存放 (b1,...,bn)
    // 算法将这两个表的位置互换
    Reverse(A, 0, m + n - 1, arraySize);
    Reverse(A, 0, n - 1, arraySize);
    Reverse(A, n, m + n - 1, arraySize);
}
```

##### 补充说明

本题的经典解法是三次逆置（原地工作），将数组视为两个段，通过三次局部逆置实现整体交换，无需额外空间

##### 修改建议

1. **改用三次逆置法**：先整体逆置，再分别逆置前 $n$ 个和后 $m$ 个元素，空间复杂度降至 $O(1)$
2. **函数签名简化**：`Swap` 的三个参数 `SqList &L, int m, int n` 即可，参考 `Exchange(DataType A[], int m, int n, int arraySize)` 的写法
