二叉排序树的查找是从 **根结点** 开始，**逐层向下比较并选择左 / 右子树的搜索过程**

1. 若二叉排序树非空，先将给定关键字与根结点的关键字比较
2. 若相等，则查找成功
3. 若不等，小于根结点的关键字，则在根结点的左子树上查找，否则在根结点的右子树上查找

这一过程具有天然的 **递归结构**，也可以用 **循环** 实现

##### 循环实现二叉排序树查找的代码示例

```c
BSTNode *BST_Search(BiTree T,ElemType key){
    while(T!=NULL&&key!=T->data){    //若树空或等于根结点值，则结束循环
        if(key<T->data) T=T->lchild;  //小于，则在左子树上查找
        else T=T->rchild;            //大于，则在右子树上查找
    }
    return T;
}
```

同样，二叉排序树的查找也可用递归算法实现，其实现较为简单，但由于递归可能导致较大的栈空间开销，执行效率较低
