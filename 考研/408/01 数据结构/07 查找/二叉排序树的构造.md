从一棵空树开始，依次将给定元素插入二叉排序树的合适位置（重复关键字将被忽略）

##### 构造二叉排序树的算法描述

```c
void Creat_BST(BiTree &T,KeyType str[],int n){
    T=NULL;          //初始时 T 为空树
    int i=0;
    while(i<n){      //依次将每个关键字插入二叉排序树
        BST_Insert(T,str[i]);
        i++;
    }
}
```
