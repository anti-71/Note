##### 1）初始化

```c
#define MAXSIZE 10
void Initial(int S[]) {
    for (int i = 0; i < MAXSIZE; i++)
        S[i] = -1;
}
```

##### 2）查找

###### 基础 Find 函数

```c
int Find(int S[], int x) {
    while (S[x] >= 0)
        x = S[x];
    return x;
}
```

###### 带路径压缩的 Find 函数

```c
int FindWithPathCompression(int S[], int x) {
    int root = x;
    while (S[root] >= 0)
        root = S[root];           // 找集合的根
    while (x != root) {
        int t = S[x];             // 标记 x 的父结点
        S[x] = root;              // 把 x 挂在 root 下
        x = t;                    // 继续处理父结点
    }
    return root;
}
```

##### 3）合并

###### 普通 Union（不按大小优化）

```c
void Union(int S[], int root1, int root2) {
    if (root1 == root2) return;
    S[root1] += S[root2];
    S[root2] = root1;
}
```

###### 按集合大小合并 UnionBySize

```c
void UnionBySize(int S[], int root1, int root2) {
    if (root1 == root2)
        return;
    if (S[root1] < S[root2]) {
        S[root1] += S[root2];
        S[root2] = root1;
    } else {
        S[root2] += S[root1];
        S[root1] = root2;
    }
}
```

**优化后的 Union 可以将集合树的高度控制在 $O(\log_2 n)$ 以内**

> [!note] 并查集标准使用方式
> 使用并查集的基本操作就是先 Find 再 Union，即 `Union(Find(x), Find(y))`
> 
> | 优化后的 Find + Union | $O(\alpha(n))$ |
> |-----------------------|----------------|

##### 4）并查集的应用

###### 应用 1：检测图中是否有环

1. 初始化并查集
2. 遍历所有边，对于 $(u, v)$：
   - Find u 所在集合的 Root u
   - Find v 所在集合的 Root v
   - 如果 Root u = Root v，加入 $(u, v)$ 会形成环
   - 如果 Root u ≠ Root v，使用 Union 合并两个集合
3. 完成遍历

###### 应用 2：实现 Kruskal 算法

1. 初始化并查集
2. 将图中所有边按权重从小到大排序
3. 遍历所有边，对于 $(u, v)$：
   - Find u 所在集合的 Root u
   - Find v 所在集合的 Root v
   - 如果 Root u = Root v，跳过
   - 如果 Root u ≠ Root v，将该边加入最小生成树，Union 合并两个集合
4. 如果最小生成树的边数已达到 $|V| - 1$，则停止；如果边不够但没有更多边可选，说明原图不连通，无法生成 MST

###### 应用 3：判断无向图的连通性

1. 初始化并查集
2. 遍历所有边，对于 $(u, v)$：
   - Find u 所在集合的 Root u
   - Find v 所在集合的 Root v
   - 如果 Root u = Root v，已连通，不做操作
   - 如果 Root u ≠ Root v，Union 合并两个集合
3. 遍历图中所有顶点，使用 Find 找到其根，如果所有顶点所在集合的根相同，则图连通
