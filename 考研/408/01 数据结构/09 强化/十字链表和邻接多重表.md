> [!note]
> 弧尾 $\xrightarrow{}$ 弧头：tail → head

##### 十字链表（有向图）

顶点结点：`data | firstin | firstout`

| 字段 | 说明 |
|------|------|
| data | 用于存放数据 |
| firstin | 指向以 data 为弧头的第一个顶点 |
| firstout | 指向以 data 为弧尾的第一个顶点 |

弧结点：`tailvex | headvex | hlink | tlink | (info)`

| 字段 | 说明 |
|------|------|
| tailvex | 弧尾指向的顶点的编号 |
| headvex | 弧头指向的顶点的编号 |
| hlink | 弧头相同的下一条弧 |
| tlink | 弧尾相同的下一条弧 |
| info | 弧的信息，一般省略 |

###### 优势

十字链表结合了邻接表和逆邻接表，可以方便地计算顶点 $v_i$ 的**入度**和**出度**，以及寻找依附于某一结点的所有弧

##### 邻接多重表（无向图）

顶点结点：`data | firstedge`

| 字段 | 说明 |
|------|------|
| data | 用于存放数据 |
| firstedge | 指向第一条依附于该顶点的边 |

边结点：`ivex | ilink | jvex | jlink | (info)`

| 字段 | 说明 |
|------|------|
| ivex | 该边依附的两顶点的编号 1 |
| ilink | 指向下一条依附于 ivex 的边 |
| jvex | 该边依附的两顶点的编号 2 |
| jlink | 指向下一条依附于 jvex 的边 |
| info | 边的信息，一般省略 |

###### 图示

![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/6402eec2e45e4c46a8e8b8569a38e8f8.png)

###### 优势

邻接多重表中，每条边只会被存储一次，且所有依附于同一结点的边都被串联在一个链表中，便于 **计算结点的度** 以及寻找依附于某一结点的所有边
