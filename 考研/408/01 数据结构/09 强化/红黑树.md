##### 1）定义与性质

###### 定义

1. 结点是红色或黑色，根结点和叶子结点必是黑色
2. 每个红结点必须有两个黑色的子结点，即不能出现两个连续的红结点
3. 从任一结点到每个叶子结点的所有路径都包含相同数目的黑色结点
4. 从某结点出发（不含该结点）到达任一叶子结点（包含叶结点）的路径上的黑结点总数即为黑高 bh

###### 性质

1. 根结点的黑高 $\geqslant h/2$
2. 从根到叶结点的最长路径 $\leqslant$ 最短路径的 2 倍：最短路径上只有黑结点，最长路径中红结点的个数 = 黑结点的个数，交替出现
3. 有 n 个内部结点的红黑树的高度 $h \leqslant 2\log_2 (n+1)$

##### 2）插入

> [!note]
> 1. 插入的新结点一定是红结点
> 2. 染色就是红黑互换

| 情况      |        |     | 操作                                          |
| ------- | ------ | --- | ------------------------------------------- |
| ① 空树    |        |     | 插入，染色                                       |
| ② 父黑    |        |     | 直接插入                                        |
| ③ 父红且叔红 |        |     | 叔父染色，祖父染色；若祖父是根结点，祖父染色，否则将祖父视为新结点，重新判断类型并调整 |
| ④ 父红且叔黑 | ④-1 LL |     | **祖父右旋**，父亲、祖父染色                            |
|         | ④-2 LR |     | **父亲左旋**，父亲看作新结点，重新判断类型并调整                  |
|         | ④-3 RR |     | **祖父左旋**，父亲、祖父染色                            |
|         | ④-4 RL |     | **父亲右旋**，父亲看作新结点，重新判断类型并调整                  |

##### 3）红黑树 vs AVL

1. 设计红黑树的目的就是解决 AVL 维护起来比较麻烦的问题，红黑树的读取略逊于 AVL，维护强于 AVL，每次插入和删除的平均旋转次数远小于 AVL
2. AVL 追求绝对严格的平衡，必须满足左右子树高度差不超过 1，而红黑树放弃追求完全平衡，它的旋转次数少，**插入最多 2 次旋转，删除最多 3 次旋转**，所以对于搜索、插入、删除操作较多的情况下，红黑树的效率是优于 AVL 的
3. 红黑树和 AVL 的插入、删除时间复杂度都是 $O(\log_2 n)$
