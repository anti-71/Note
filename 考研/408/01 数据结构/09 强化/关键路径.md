##### 1）四个时间参数

| 参数                     | 计算方式                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| 事件 $v_i$ 的最早发生时间 $v_e$ | $v_e$（源点）= 0<br>$v_e(k) = \max\{v_e(j) + \text{Weight}(V_j, V_k)\}$，$v_k$ 为 $v_j$ 的任意后继         |
| 事件 $v_i$ 的最迟发生时间 $v_l$ | $v_l$（汇点）= $v_e$（汇点）<br>$v_l(k) = \min\{v_l(j) - \text{Weight}(V_k, V_j)\}$，$v_k$ 为 $v_j$ 的任意前驱 |
| 活动 $a_i$ 的最早开始时间 $e$   | 该弧起点顶点的 $v_e$                                                                                   |
| 活动 $a_i$ 的最迟开始时间 $l$   | 该弧终点的顶点的 $v_l$ 减去弧的权值                                                                           |

##### 2）关键活动与关键路径

1. 活动的时间余量 = $l - e$
2. 关键活动的时间余量为 0（$l = e$），关键活动组成了关键路径
3. 关键路径可能不唯一
4. 关键路径是持续时间最长（权值之和最大）的那条路径
5. 缩短关键路径，并不一定导致整个工期加快
   - 如果只有一条关键路径，**缩短关键路径，一定导致整个工期加快**
   - 如果有多条关键路径，**缩短关键路径，不一定导致整个工期加快**，因为缩短了路径长度的那条关键路径将不再是关键路径
   - 缩短 **所有关键路径上共有的** 任意一个关键活动的持续时间才会导致整个工期加快
   - 延长 **任意一条关键路径上** 的关键活动的持续时间都会导致整个工期减慢
6. 求关键路径是以拓扑排序为基础的
