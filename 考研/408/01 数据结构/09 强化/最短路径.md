##### 1）Dijkstra 算法

**辅助数组**：

| 数组 | 作用 |
|------|------|
| final[] | 标注各顶点是否已找到最短路径 |
| dist[] | 最短路径长度 |
| path[] | 路径上的前驱 |

**算法步骤**：

1. 初始化三个数组信息
2. 观察 final[] 数组，若 final[i] = 0 且 dist[i] 最小，则将 final[i] 改为 1，收录该顶点 $v_i$ 到最优路径集合中
3. 对 $v_i$ 的邻接点 $v_j$ 做如下判断：如果 dist[i] + $\langle v_i, v_j \rangle$ 的权值 < dist[j]，则更新 dist[j] 与 path[j]
4. 循环步骤 2 和 3，直到所有顶点都找到最短路径

> [!warning] 注意
> Dijkstra 用于求解 **单源最短路径**，**不适用于带负权值的图**
> 
> Dijkstra 算法的时间复杂度为 $O(|V|^2)$

##### 2）Floyd 算法

**算法步骤**：

1. 初始化矩阵
2. 依次选择顶点作为中转点
3. 以中转点为中心，画出横、竖、对角线三条彩带，彩带上的数字不变，逐个检查彩带外的每个数字，若该数字所在行、列对应的彩带上的值相加小于数字本身，则用更小的值替换，否则保持不变
4. 循环步骤 2 和 3，直到找到所有顶点对之间的最短路径

> [!warning] 注意
> Floyd 用于求解 **各顶点之间的最短路径**，**不适用于带负权回路的图**
> 
> Floyd 算法的时间复杂度为 $O(|V|^3)$
