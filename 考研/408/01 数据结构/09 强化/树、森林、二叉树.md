##### 1）转换规则

| 树和二叉树 | | 二叉树和森林 | |
|-----------|--|-------------|--|
| 树 ⟷ 二叉树 | 左孩子<br>右兄弟 | 二叉树 → 森林 | 二叉树的根、根的右孩子、根的右孩子的右孩子……均为森林中树的根结点<br>其余按照左孩子右兄弟转换 |
| | | 森林 → 二叉树 | 森林中所有树的根结点组成二叉树的根、根的右孩子、根的右孩子的右孩子……<br>其余按照左孩子右兄弟转换 |

##### 2）森林中树数量的判定

1. 二叉树中从根结点开始，一直沿右孩子指针向下所经过的结点个数 = 对应森林中树的数量
2. 森林中树的数量 = 对应二叉树中从根结点开始，一直沿右孩子指针向下所经过的结点个数

##### 3）单树 / 森林的区分

1. 二叉树的根结点 **没有** 右子树 → 转换后是一棵树
2. 二叉树的根结点 **有** 右子树 → 转换后是一个至少有两棵树的森林

##### 4）树转二叉树后无右孩子的结点

1. 树的根结点以及每个非终端结点的 **最后一个孩子** = 二叉树中 **没有右孩子** 的结点
2. 二叉树中 **没有右孩子** 的结点 = 树的根结点以及每个非终端结点的 **最后一个孩子**

##### 5）遍历对应关系

| 树 | 二叉树 | 森林 |
|---|--------|------|
| 先根遍历 | 先序遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 | 中（后）序遍历 |

如果不知道如何对树和森林进行遍历，可先转化为二叉树，再对二叉树进行相应的遍历
