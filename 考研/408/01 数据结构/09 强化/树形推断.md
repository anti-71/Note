1.  $N = n_0 + n_1 + n_2 + \dots + n_n = 0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 + \dots + n \cdot n_n + 1$
   
   结点总数 $N =$ 度之和（分支数） + 1
   
2.  非空二叉树满足 $n_0 = n_2 + 1$
3.  度为 $m$ 的树第 $i$ 层上最多 $m^{i-1}$ 个结点
4.  高度为 $h$ 的满 $m$ 叉树一共有 $\displaystyle \frac{m^h - 1}{m - 1}$ 个结点
5.  具有 $n$ 个结点的完全二叉树的高度为 $\lceil \log_2 (n + 1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$
6.  对完全二叉树按照层序进行编号，$i = 1, 2, \dots, n$：
    - $i$ 为偶数时，父结点为 $i / 2$，$i$ 是父结点的左孩子；$i$ 为奇数时，父结点为 $(i - 1) / 2$，$i$ 是父结点的右孩子
    - $i$ 的左孩子为 $2i$ 或不存在，$i$ 的右孩子为 $2i + 1$ 或不存在
    - $i \leqslant \lfloor n / 2 \rfloor$ 时，$i$ 为分支结点；$i > \lfloor n / 2 \rfloor$ 时，$i$ 为叶子结点
    - 若 $n$ 为奇数，则每个分支结点都有左右孩子；若 $n$ 为偶数，则 $i = n / 2$（最后一个分支结点）只有左孩子
7.  完全二叉树中度为 1 的结点（$n_1$）只可能有 1 个或者 0 个
8.  树越高越细（每层结点数量少），越矮越胖（每层结点数量多）
9.  完全二叉树只有最后两层可能出现叶结点
