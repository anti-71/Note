##### 1）括号匹配

括号匹配需要解决的问题：
1. 左括号必须用相同类型的右括号闭合
2. 左括号必须以正确的顺序闭合
3. 每个右括号都有一个对应的相同类型的左括号

每当出现一种左括号，计算机便等待对应的右括号，但在此期间若出现了另一种左括号，则将其视为更高优先级，转而等待新类型的右括号，若遇到当前等待的右括号，则成对消除

##### 2）表达式求值

| | 中缀表达式求值 | 后缀表达式求值 | 前缀表达式求值 |
|--|---------------|---------------|---------------|
| 扫描方向 | 从左到右 | 从左到右 | 从右到左 |
| 遇到操作数 | 直接入操作数栈 | 直接入操作数栈 | 直接入操作数栈 |
| 遇到操作符 | 依次弹出栈中优先级大于等于当前运算符的所有操作符（碰到左括号或栈空停止），每出栈一个操作符将操作数栈顶两个元素取出计算，结果压入操作数栈，最后将当前操作符入操作符栈 | 弹出栈顶两个操作数进行计算，结果压栈 | 弹出栈顶两个操作数进行计算，结果压栈 |
| 操作数出栈顺序 | — | 第一个出栈的在运算符右边 | 第一个出栈的在运算符左边 |
| 括号处理 | 左括号入栈，右括号触发依次弹出直到左括号弹出 | 无括号 | 无括号 |

表达式扫描结束但操作符栈非空时，依次弹出操作符栈中的符号并计算

##### 3）中缀表达式转后缀表达式（最常考）

| 步骤    | 规则                                                  |
| ----- | --------------------------------------------------- |
| 扫描顺序  | 从左到右扫描                                              |
| 遇到操作数 | 直接输出，不做栈操作                                          |
| 遇到运算符 | 依次弹出栈中优先级大于等于当前运算符的所有运算符并输出，碰到左括号或栈空停止，最后入栈当前扫描的运算符 |
| 遇到界限符 | 左括号入栈，右括号依次弹出栈中运算符并输出直到左括号弹出                        |
|       |                                                     |
