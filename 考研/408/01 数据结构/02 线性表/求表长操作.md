求表长是指统计单链表中 **数据结点的个数**（不包括头结点）

从第一个数据结点开始依次遍历，为此需设置一个计数变量，每访问一个结点，其值加 1，直到遇到 NULL

```c
int Length(LinkList L){
    int len=0;                       //计数变量，初始为0
    LNode *p=L;
    while(p->next!=NULL){
        p=p->next;
        len++;                       //每访问一个结点，计数加1
    }
    return len;
}
```

求表长操作的时间复杂度为 O(n)

另需注意的是，因为表长不包括头结点，因此不带头结点和带头结点的实现细节略有不同
