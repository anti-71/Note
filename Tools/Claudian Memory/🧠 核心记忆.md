## 📝 笔记写作规范

### 图片处理
- **只用 OSS 外链**，不在 vault 中保存图片文件
- 格式：`![](https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/文件名)`
- 写笔记流程：识图 → 上传 OSS → 插入外链
- 笔记中的图片引用不要用 `![[本地路径]]`，一律用 OSS URL

### Markdown 风格
- 使用 Wiki-link `[[链接]]` 引用 vault 内其他笔记
- 公式：行内 `$...$`，块级 `$$...$$` 或 `\begin{aligned}...\end{aligned}`
- 层级标题用 `#` 号，最多 `######`
- **加粗** 表示关键术语或重要概念
- **不写句号** — 中文内容句尾不加任何句号（不用 `。` 也不用 `.`），自然断句换行即可

## 📖 用户笔记风格（考研笔记）

### YAML Frontmatter 格式
```yaml
---
名称: 笔记名称
章: 第X章 章节名
节: "[[父级章节笔记]]"    # 可选，用 Wiki-link
tags:
  - 知识点              # 或 章节（仅导航页用）
index: 序号             # 数字排序
---
```

- **无** `created` / `updated` / `aliases` 字段
- `节` 字段用 Wiki-link 格式，加引号

### 笔记类型

#### 1️⃣ 章节导航笔记（tag: `章节`）
- 用 `### 一、` / `### 二、` 分节
- 子条目用 `- #### [[文件名|编号. 名称]]`，编号在每个 `###` 小节内**重新从 1 开始**
- 若某 `###` 小节下**只有单个链接**，则**不加编号**，直接用 `- #### [[文件名]]`
- 每个小标题下是知识点链接列表
- 节内如含详细说明，用普通段落直接写在对应小节下
- 注：本科笔记用 `### 第一节 xxx` 分节，链接格式同上 `[[文件名|编号. 名称]]`

#### 2️⃣ 原子知识点笔记（tag: `知识点`）
- **一个文件只讲一个概念**
- 开篇直接给出定义/结论，关键术语**加粗**
- 标题层级：只能用 `#####`，最多延伸到 `######`（禁止 `#` ~ `####`）
- 可含：代码块（` ```c `）、公式、表格、callout

### 公式风格（LaTeX）
- 行内：`$...$`
- 块级：`$$...$$` 或 `\begin{aligned}...\end{aligned}`，行间公式与中文汉字间应加空格
- 分数统一用 `\dfrac`，不用 `\frac`（行内行间皆如此）
- 小于等于用 `\leqslant`，大于等于用 `\geqslant`（不用 `\le`/`\ge`/`\leq`/`\geq`）
- 单向箭头用 `\implies`，双向箭头用 `\iff`（不用 `\Rightarrow`/`\Leftrightarrow`）

### 中文排版
- 数字、英文字母/单词、行间公式与中文汉字之间须间隔 1 个空格
- 对齐：`\begin{align*}` 配合 `&`
- 分段定义：`\begin{cases}...\end{cases}`
- 分数：`\dfrac`
- 箭头：`\implies`（推出）、`\iff`（等价）
- 下标：`$..._i$` 或 `$..._{...}$`
- 集合：`\mathrm{C}_n^2`
- 大于等于/小于等于：`\geqslant` / `\leqslant`

### 特殊元素
- **Callout**: `> [!note]` 若需标题则写同行 `> [!note] 标题`，若**无标题**则 `[!note]` 独占一行，内容从下行开始
- **代码块**: 标注语言，如 ` ```c `
- **表格**: 标准 Markdown 表格 `|...|...|`
- **加粗**: 定义中的核心术语加粗
- **链接**: 知识点内部用 `[[笔记名]]` 相互引用
- **换行**: 段落间用两个换行符（即空一行），不用单个换行

### 知识组织方式
- **原子化**：每篇笔记独立、聚焦一个知识点
- **目录结构**：`学科/章节号 名称/知识点名称.md`
- **导航页**：`00 索引/` 下放 DataviewJS 学科导航
- **交叉引用**：知识点笔记通过 `节` 字段关联到章节目录
- 文件夹名带数字前缀排序（如 `01 绪论`、`02 线性表`）
