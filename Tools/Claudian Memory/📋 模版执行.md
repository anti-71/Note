# 📋 模版执行

> 模版位于 `Tools/模板/`（排除 `电视剧.md`、`电影.md`、`书籍.md` 三个内容类模版）
> 当用户要求"用模版"或请求内容匹配模版功能时加载

---

## 触发关键词

| 用户请求特征 | 对应模版 |
|------------|---------|
| 打开/跳转到今天的安排、今日学习 | `Open Study Note` |
| 创建日计划、今日学习安排 | `Daily Learning Plan` |
| 创建周计划、本周安排 | `Weekly Learning Plan` |
| 创建月计划、本月安排 | `Monthly Learning Plan` |
| 创建季度计划 | `Quarterly Learning Plan` |
| 帮我安排、创建计划（季/月/周/日） | `Learning Plan Generator` |
| 添加学习任务、生成任务、学英语/数学/408 | `Study Task Generator` |
| 插入 callout、引用块、提示框 | `Insert Callouts` |

---

## 各模版执行流程

### 1. Open Study Note — 打开今日学习安排

**模版意图**：跳转到 `学习安排/YYYY/MM/MM-DD.md`

**执行流程**：

```
1. 获取当天日期 path = 学习安排/{YYYY}/{MM}/{MM-DD}.md
2. 若文件存在 → 输出 "今日安排已就绪：[[{path}]]"
3. 若文件不存在 → 先问用户是否创建
   - 是 → 用 Daily Learning Plan 模版创建
   - 否 → 告知路径
```

### 2. Daily Learning Plan — 创建日计划

**模版意图**：生成带 dataview 计分板的每日学习安排

**执行流程**：

```
1. 确认日期（默认今天，可指定）
2. 路径 = 学习安排/{YYYY}/{MM}/{MM-DD}.md
3. 若已存在 → 告知并打开
4. 若不存在 → 创建文件，写入 YAML frontmatter + 结构
```

**模版结构还原**：

````markdown
---
type: 学习安排
date: {YYYY-MM-DD}
学习得分: 0
---

# 📅 学习安排 | {YYYY-MM-DD}

## 📚 今日学习得分

```dataviewjs
// 计分逻辑：复习*0.1 + 学*0.2 + 错题*3.0 + 分钟*0.15
// 会自动更新 YAML 学习得分
```

## ⏳ 倒计时

考研倒计时：还有 {距离 2026-12-19 的天数} 天

## 📊 今日学习目标

（下方可添加任务列表）
````

> 创建后提醒用户：可在 Obsidian 中打开查看 dataview 计分板

### 3. Weekly Learning Plan — 创建周计划

**模版意图**：生成周计划含每日热力图 + 未完成任务汇总

**执行流程**：

```
1. 确认周次（默认本周，可指定）
2. 路径 = 学习安排/{YYYY}/{MM}/第{WW}周.md
3. 检查路径所在月份（周可能跨月，取周一所在月）
4. 创建文件，写入结构
```

### 4. Monthly Learning Plan — 创建月计划

**模版意图**：生成本月计划含全月热力图

**执行流程**：

```
1. 确认月份（默认本月，可指定 YYYY-MM）
2. 路径 = 学习安排/{YYYY}/计划管理/{MM}.md
3. 创建文件
```

### 5. Quarterly Learning Plan — 创建季度计划

**模版意图**：生成季度计划

**执行流程**：

```
1. 确认季度（默认当前 Q1/Q2/Q3/Q4）
2. 路径 = 学习安排/{YYYY}/计划管理/季度Q{季度}.md
3. 创建文件，写入核心目标结构
```

### 6. Learning Plan Generator — 计划生成器（选择器）

**模版意图**：让用户选择季度/月/周/日，自动创建对应计划

**执行流程**：

```
问用户：要创建什么计划？（季度 / 月 / 周 / 日）
→ 根据选择，调用对应模版（3/4/5/2）的执行流程
```

### 7. Study Task Generator — 学习任务生成

**模版意图**：交互式引导用户选择科目类型，生成任务条目

**执行流程**：

```
1. 根据用户给出的信息判断科目和子类（如"概率论-网课"→数学+概率论+网课）
2. 用户若未提供具体数值，直接按模版占位符写入，不再追问
3. 将生成的任务条目添加到当天的学习安排文件中
4. 任务条目按照 "科目-子类-类型: 具体内容" 格式
```

**任务格式参考**：

| 类型 | 格式 |
|------|------|
| 网课 | `{科目}-{子类}-网课:   节,   分钟` |
| 做题 | `{科目}-{子类}-做题: {书名}: [章节] (  /  ),   分钟` |
| 错题整理 | `{科目}-{子类}-错题整理:   题` |
| 背单词 | `英语-背单词: 复习   词, 学   词` |
| 外刊 | `英语-外刊:   篇,   分钟` |
| Anki | `Anki:   分钟` |
| 本科学习 | `本科学习-{科目}:   分钟` |

**任务条目格式**：

```
- [ ] {科目}-{子类}-{类型}: {具体内容}
```

### 8. Insert Callouts — 插入提示框

**模版意图**：生成 Obsidian callout 块

**执行流程**：

```
1. 问用户：需要哪种 callout 类型？（note/info/todo/tip/abstract/question/quote/example/success/warning/failure/danger/bug）
2. 问用户：标题？（除 example/question 外可选）
3. 问用户：内容？
4. 输出 callout 格式
```

**输出格式**：

```markdown
> [!type] 标题
> 内容
```

|---------|---------|

## 注意事项

1. 所有计划模版依赖 Obsidian 插件（Templater/Dataview/Button）在 Obsidian 内才能完全生效
2. 我的角色是**按模版意图生成 Markdown 文件**，动态渲染（dataviewjs）需在 Obsidian 中查看
3. 创建日安排时，若当天已存在文件，先读取再追加任务，不可覆盖
4. 创建周/月/季度计划时，检查路径不冲突
