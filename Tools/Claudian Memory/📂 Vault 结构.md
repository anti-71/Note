# 📂 Vault 结构

> 此文件记录 vault 目录结构和文件夹约定
> 当任务涉及文件管理、目录导航、创建新笔记时加载

---

## 目录布局

```
Note/                          ← Vault 根
├── 00 索引/                   ← DataviewJS 学科导航页
├── 考研/                      ← 考研科目笔记
│   ├── 01 高等数学/
│   │   ├── 01 函数与极限/
│   │   └── 02 导数与微分/
│   └── ...
├── 本科/                      ← 本科课程笔记
│   └── ...
├── Tools/
│   ├── Claudian Memory/       ← 记忆模块（当前文件所在）
│   ├── 模板/                   ← 笔记模板
│   └── 🏠 Home.md             ← 个人主页
└── .obsidian/                 ← Obsidian 配置
```

---

## 文件夹命名约定

- 数字前缀排序：`01 名称`、`02 名称`
- 学科/章节文件夹：`数字 名称` 格式
- 知识点文件：直接使用知识点名称

---

## 参考位置

| 位置 | 用途 |
|------|------|
| `Tools/Claudian Memory/` | 记忆模块 |
| `Tools/模板/` | 笔记模板（学习计划、书籍、电影等） |
| `00 索引/` | DataviewJS 学科导航 |
| `.obsidian/` | Obsidian 插件与核心配置 |
