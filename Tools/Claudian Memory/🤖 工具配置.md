# 🤖 工具配置

> 此文件包含 OSS 图床、识图工具和组合工具的配置
> 当任务涉及图片上传、识图、工具调用时加载

---

## 1. 图床 — 阿里云 OSS

| 项目 | 值 |
|---|---|
| Bucket | `shiyuzhe` |
| Endpoint | `oss-cn-hangzhou.aliyuncs.com` |
| 图床目录 | `Tuchuang/` |
| URL 前缀 | `https://shiyuzhe.oss-cn-hangzhou.aliyuncs.com/Tuchuang/` |
| 上传脚本 | `oss-upload <图片路径>`（位于 `~/.local/bin/oss-upload`） |
| 输出 Markdown | `oss-upload --md <图片路径>` |
| 密钥位置 | `~/.claude/skills/claude-vision-skill/.env.oss` |
| **规则** | **只用 OSS 外链，本地不保存图片** |

---

## 2. 识图 — 通义千问 VL

| 项目 | 值 |
|---|---|
| 模型 | `qwen-vl-max` |
| 脚本 | `~/.claude/skills/claude-vision-skill/vision.js` |
| API Key | 存于 `~/.claude/skills/claude-vision-skill/.env` |
| 调用方式 | `node ~/.claude/skills/claude-vision-skill/vision.js <图片路径> <识图Prompt>` |
| 识图Prompt | 详见 [[🖼️ 识图规则.md]] |
| 注意 | vision 命令依赖 `DASHSCOPE_API_KEY`，`node_modules` 在 skill 目录下 |

---

## 3. 组合工具

| 工具 | 作用 |
|---|---|
| `oss-upload --md <图片>` | 上传 OSS + 输出 `![](url)` |
| `img-process <图片>` | 识图 + 上传 OSS 一条龙 |

> 涉及上述脚本的具体调用方式，见 [[🖼️ 识图规则.md]] 的"调用示例"部分
