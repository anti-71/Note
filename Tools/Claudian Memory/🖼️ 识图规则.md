## 完整识图 Prompt

调用 `vision.js` 识图时，**必须将以下规则作为 prompt 传给 `vision.js` 的第二个参数**（`[问题]` 位置）：

```
请将图片内容完整提取并转换为 Markdown 格式，严格遵循以下规则：

1. 内容保真：不得修改、删减或润色原图文字。

2. 标点与换行规范：
   - 全文严禁出现中文句号"。"，若原图中出现句号，请直接替换为换行
   - 正文统一使用中文全角标点，如"，"和"（）"；仅在代码块或公式块内部使用英文半角标点 `,` 和 `()`

3. 格式要求：
   - 题号统一使用（1）（2）（3）格式（严禁使用反引号包裹）
   - 选项统一使用（A）（B）（C）（D）格式（严禁使用反引号包裹）
   - 若数字前后均为汉字，需在数字前后各加一个空格（例如：共 5 个）
   - 结构优化：尽量减少使用 Markdown 数字列表（1. 2. 3.），对于具有层级的内容，最小单位应使用五级小标题（#####）进行呈现
   - 五级标题序号形式：五级标题（#####）的序号必须以"1）""2）""3）"的形式开头

4. 符号禁令：严禁在行内正文中使用反引号 `` 包裹任何字符、题号或选项

5. 公式与符号规范：
   - 仅对数学公式使用 $ 包裹，$ 前后严禁出现空格；纯数字不需要包裹
   - 小于等于、大于等于符号必须使用 \leqslant 和 \geqslant
   - 对于单向箭头以 \implies 输出，对于双向箭头以 \iff 输出
   - 向量使用加粗文本处理，不得加方框
   - 在 LaTeX 公式块中，若存在连等式，必须使用 \begin{aligned} 和 \end{aligned} 进行对齐处理
   - 行内公式的极限形式下标要用 _\limits

6. 视觉标注：对原图中不同颜色的字进行加粗处理

7. 交互要求：直接输出结果，不要询问任何额外问题

8. 图片间距：不同图片之间不要加分割线（---），直接连续输出内容
```

## 调用示例

```bash
node ~/.claude/skills/claude-vision-skill/vision.js "<图片路径>" "请将图片内容完整提取并转换为 Markdown 格式，严格遵循以下规则：...

（规则内容同上）"
```
