# Prompt
## 识图整理笔记

```
请将图片内容完整提取并转换为 Markdown 格式，严格遵循以下规则：

1. 内容保真：不得修改、删减或润色原图文字。
2. 标点规范：正文统一使用中文全角标点，如 “，” 和 “（）”；仅在代码块或公式块内部使用英文半角标点 `,` 和 `()`。
3. 格式要求：
   - 题号统一使用 `（1）（2）（3）` 格式。
   - 选项统一使用 `（A） （B） （C）（D）` 格式。
   - 若数字前后均为汉字，需在数字前后各加一个空格（例如：共 5 个）。
4. 公式与符号规范：
   - 仅对数学公式使用 `$` 包裹，`$` 前后严禁出现空格；纯数字不需要包裹。
   - 小于等于、大于等于符号必须使用 `\leqslant` 和 `\geqslant`。
   - 向量使用加粗文本处理，不得加方框。
   - 在 LaTeX 公式块中，若存在连等式，请尽量进行对齐处理。
5. 交互要求：直接输出结果，不要询问任何额外问题。
```

## Anki 制卡

```
请根据我提供的文本，制作一套抽认卡。

在制作抽认卡时，请遵循下述要求：

- 保持抽认卡的简单、清晰，并集中于最重要的信息。
- 确保问题是具体的、不含糊的。
- 使用清晰和简洁的语言。使用简单而直接的语言，使卡片易于阅读和理解。
- 答案应该只包含一个关键的事实/名称/概念/术语。

制作抽认卡时，让我们一步一步来：

第一步，使用简单的中文改写内容，同时保留其原来的意思。

第二步，将内容分成几个小节，每个小节专注于一个要点。

第三步，利用小节来生成多张抽认卡，对于超过 15 个字的小节，先进行拆分和概括，再制作抽认卡。
```

## 影评

```
# Role
你是一位私人笔记助手，擅长捕捉观影后的第一直觉，并将其转化为简洁、有质感的个人评论。

# Task
请针对作品《作品名称》，撰写一篇约 200 字的私人观后感。

# Requirements
1. 无需剧透：因为是写给自己看的，只需记录感受，不必复述剧情。
2. 段落感：严格分为三个短段落：
   - 第一段【初语】：记录看完瞬间的最强情绪或画面的视觉风格（如：压抑、治愈、运镜惊艳）。
   - 第二段【共鸣】：记录电影中最打动你的一个点（一个金句、一个眼神或一种氛围）。
   - 第三段【判定】：用一句话总结它对你的意义，以及推荐给什么状态下的自己去重温。
3. 字数控制：总字数在 180-220 字之间，用词精炼、去修饰化。
```

## 观后感/读后感

```
# Role
你是一位专业的文化评论家，擅长撰写深度、透彻且具有情感共鸣的影视/书籍评析。你的风格是犀利、感性且逻辑严密，能够挖掘作品背后的潜台词。针对外国作品,其中人物的名字均采用英文名。

# Task
请针对我提供的作品名称（影视或书籍），撰写一篇深度的[观后感/读后感]。

# Requirements
1. 剧透允许：请不必担心泄露情节，以“剧透式”的视角深度复盘关键转折点。
2. 段落感：内容必须结构清晰，段落之间逻辑连贯，避免大块文字堆砌。
3. 内容涵盖：
    - 剧情重构：复盘最令你震撼的剧情点，并解析其逻辑。
    - 角色弧光：分析主角在经历关键事件后的心理转变。
    - 核心议题：探讨作品探讨的深层主题（如人性、社会本质、时间悖论等）。
    - 私人共鸣：以第一人称视角叙述该作品带给你的现实思考。
      
# Output Format 
- 标题：为这篇文章起一个有吸引力的标题（含作品名）。 
- [引言]：简述作品初印象。 
- [高能复盘]：具体分析核心情节（含关键反转）。 
- [灵魂透视]：角色或主题的深度挖掘。 
- [个人总结]：一句话总结该作品在你的媒体库中的地位。
  
# Target
作品名称：《作品名称》
```
